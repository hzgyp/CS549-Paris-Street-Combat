# Standard Unreal navigation comparison

Read the synchronized UE_STANDARD_NAV_IMPLEMENTATION and result in
Docs/Development/MissionLoopV1, plus ML013/14/17/18/19/20 before any new work.
The explicit user instruction authorizes this distinct comparison; old movement
banks and launchers remain locked and all old raw evidence is retained.

`prepare.py` freezes the original69 sites and138 role cases with their previous
outcomes and703 current guards, then creates `ue_standard.py` from the admitted
fixture plus `standard_api.py`. It never modifies the old observer or helper.
`run_standard.ps1` uses unique owned engine identities:

- SavedProbe:138 original-body standing checks and standard MoveToLocation
  requests, intentionally cancelled before travel. Request admission only.
- Early: unsaved full navigation rebuild, then four real standard native moves.
- Full: independently audited Early gate, same unsaved rebuild,134 other real
  moves; no repeat of the four early actual movements.

`audit.py` checks frozen cases, current native request paths/events, actual
standing/dwell/trajectory, source and guard protection, and normal exit/log.
`finish.py` derives measured figures and condition-specific masks, authenticates
private failure copies and writes synchronized results/handoff. Commercial
bytes, native screenshots, raw exports/trajectories and private receipts remain
under ignored private Evidence/UEStandardNavigationV1. Completed closure locks
all entries; no automatic navigation save, adoption or further retries.

Saved request results and expanded physical results have different scopes and
must not be combined as one production-navigation acceptance. Geometry white
does not certify all original characters, crowd capacity or complete floors.
