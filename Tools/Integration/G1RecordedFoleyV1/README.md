# Recorded Foley review tooling

Read Docs/Development/G1_AUDIO_REALISM_REVISION_20261009.md, CURRENT_AUDIO_REVIEW
and MI015 first. This lane changes one nonreflected helper on exact AVv3 source,
uses licensed recorded references and freezes the approved gunshot. Human in-game
listening acceptance remains pending. Do not operate OBS or create a new video
until that user gate passes; turning is documented only.

The actual run used intake -> inspect_refs/inspect_turn (old footage only) ->
prepare_audio -> prepare_source -> build -> existing actions/legacy checks ->
verify_checks -> deliver. A deliver launcher-link/count failure is frozen; bounded
recover_launcher and admit_delivery recover exact parent bytes and admit the
occupied91-file candidate without replaying the failed delivery/build/game.
Fresh preparation identities must not overwrite existing candidates or receipts.

intake keeps primary CC0 pages and explicitly published HQ MP3 media/hash receipts;
it does not bypass login to acquire original WAVs. prepare_audio performs bounded
decode/trims/gains/fades/layering, no oscillators or time/pitch changes. SOURCE and
AUDIO manifests record exact output identities. Official MP3 references are lossy,
not lossless masters. `Listen` examples are constructed materials, not captured
gameplay or an exported video soundtrack. Actual UE diagnostic WAVs also do not
establish wall-clock audiovisual cadence or realism.

Use a new owned source/build identity for further changes. Mutable launchers and
Audio are independently copied; never edit immutable linked payloads in place.
Preserve parent AV42/HUD40/native/canonical originals and both old/new evidence.
Normal playtest has no observer/audit/background override and retains V5 save
schema in an isolated normal UserDir. No automatic commit/push/SFTP/publication.
