## 已读失败与对应改变

NI001：原换弹正常终态为Ready且ActionID推进一次，不错误取消；沿用原身份、弹药守恒与取消门槛。NI003：原始偏移、投影、完整路径、真实到达分开；核对控制器朝向与演员朝向，同时两人体测不能由顺序单人体测替代。MI005：请求成功、SquadFailed=false不等于移动；记录实际进度和中止所有者。MI006：GetNavAgentLocation脚点起算，目的地声明坐标；目标变动不能每帧清空耗尽预算。ML020：保存/未保存扩展范围不同，查询预算耗尽不能称地形不可达。MI027：桥接会在Brain外停止MoveTo，避险需有限明确所有权与恢复。

最早可证伪门槛：墙后目标无 sight事件，隐蔽移动不改变敌军记忆或目的地。出现隐藏坐标读取、过期代次接纳、无限请求、穿墙/重叠、同一个支援点、受保护源码漂移即停止该候选；保留失败身份后做新运行，不覆盖失败证据。

## 行为与算法

共享优先BT，私有BB：死亡/冻结 → 已准入动作/短暂避险所有权 → 可见敌人战斗 → 有界记忆调查/搜索 → 阵营角色。状态机是意图和调试标签，不另造动作事务。视野需要存活敌对、范围、视角、遮挡；听觉只给噪声事件位置与不确定性，不提供实时Actor位置或射击许可。盟军报告是带时间的不可变观察，过期后失效，不能共享活体实时坐标。

德军：Guard→Alert→Engage→Investigate→Search→Return→Guard；任何存活状态可重新目击。警戒停留/失联宽限减少抖动。一次搜索固定截止且点数有限，重复听声不能无限延期。只有实测作者路线才允许步行巡逻；本次不选新路线。

盟军分别Follow/Regroup及Support/Overwatch。候选最多8个、两人组合最多64对：先拒绝无支撑/层不符/胶囊不通/路径不完整/超角色或玩家包络/预约冲突，再效用评分。Support偏向遮挡掩护、合适射程、短路程、靠近玩家；Overwatch偏向观察/射击通道和分离。只对**观察到的威胁位置**计算掩护；同分按稳定ID，换点需分差/停留门槛，抵达仍持有预约，换任务/失败/死亡/恢复释放。初始两人无需匈牙利、学习或LLM；扩军另评估节奏/导航/性能。

生产接入 Blueprint 优先：AI Perception事件→BB/BT→效用/协调→NavMesh/MoveTo→原动作适配。EQS待实测掩体数据到位后作为候选生成/测试层，暂以蓝图评分函数复用同一特征。拟选Detour Crowd一种局部避让，实际胶囊运行通过后定，不能叠加RVO。离线有限网格BFS仅为假设几何适配，不是巴黎导航、自研战术A*或UE避让证明；预算耗尽标Unknown/BudgetExceeded，不能标不可达。本包不需C++。Python是可执行规则oracle，JavaScript只回放日志，未来蓝图必须跑同一输入/输出向量。

```text
地图/角色登记 → 有限观察(id,位置,时间,感官,不确定性)
每名NPC → 私有目标评分/记忆 → BT意图及原因
盟军观察报告/候选评分 → 协调器 → 不同的预约点
意图 → 单移动/动作所有者(代次,请求ID,脚点,截止)
匹配回调 → 实际进度/结果 → 最多两次恢复 → Waiting
全链路证据 → 回放/UE一致性向量；不传隐藏Actor变换
```

## 参数、执行顺序与验收

`Tools/Simulation/NPCAIV2/policy.json`统一调参；单位米/秒，UE位置乘100并从原生脚点起算。固定seed54917，0.1秒步长、0.2秒感知、0.5秒决策，最多30秒；回放0.5秒采样，原始完整日志保留。视距14米、120度FOV、听距10米（墙体衰减是假设）、失联宽限0.6秒、警戒0.5秒、搜索6秒/最多4点、记忆8秒、重规划间隔0.6秒、每移动事件最多2重试、每NPC/30秒最多8尝试、单查询最多700格、目标/掩体最多8。全部是**模拟夹具默认值**，没有替代旧850/900/1000厘米规则的授权。

先冻结源码/原生身份→本文与英文→独立policy/导航/场景→有限运行及完整日志→不变量/参照/帧率测试→回放实查→结果/文件函数哈希交接。只新增 `Tools/Simulation/NPCAIV2`、`tmp/npc-ai-v2-20261017` 和本篇文档目录，不创建试玩包或UserDir，不执行历史UE脚本、不启动服务/定时器。

场景覆盖遮挡失联再发现、搜索期限、墙后听声、目标失效、不可达、真实模拟卡住、两人同时掩护/跟随、瓶颈令牌、阈值抖动、帧率调度及5NPC有限负载。同场景比较直接追踪/独立同点参照。量化隐藏坐标非法读、记忆漂移、转换数、搜索时长/点数、过期回调、查询/扩展/重试/等待、实际误差、分离、预约保持/释放、参照碰撞和Python时间。Python耗时不等于UE帧率。

离线通过要求不变量、同seed可重复、相同输入对照、实际假设场景位移和回放控件实用；不等于正式游戏/巴黎地图/课程验收。保留所有失败、实际earned saves、已验收模型动作资源。回滚是保留候选未选中，无删除/共享整树恢复。未来整合需最新基线重核、精确改动函数/文件/哈希及协作收据。
