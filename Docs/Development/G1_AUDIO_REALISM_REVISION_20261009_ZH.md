# G1 实录音效修订与录屏暂停

2026年10月9日。状态：已形成实施方案，尚未验收。英文原件见同名文档。

用户认可当前枪声，否决脚步与换弹机械声的真实感，并指出动作演示开头的
突兀回头。声音先修；转身问题本次只记录。用户人工听感复查通过之前，
不录新屏幕视频，不重新导出演示。

已读 AGENTS、HANDOFF、当前开发基线 JSON/MD、旧包退役方案、当前42文件
修复选择器及 MI012、MI013、MI014。前两例说明数值通过不等于玩家或视觉认可；
MI014 的非零混音与同步只能证明播放，不能证明真实。MI015 单独保存本次否决。

以 AVv3 的精确42文件和49da3a2c…28ad9c程序为起点，保留 HUDv3 父基线、
模型、骨骼、手指姿势、枪械/弹药事务、HUD、存档格式、直接恢复死亡终态及
原始用户文件、旧录屏。认可的 fire.wav、音量、时机和空间处理均冻结。

先找有许可的真实硬地靴步和 M1 Garand 机械录音，检查原声及旧换弹画面后
裁剪；保存来源/许可链接、下载字节哈希、处理步骤和输出 WAV 身份。优先只改
声音数据、复用原程序，另建试听包，不覆盖旧 Audio。若必须改触发时机，需另建
源副本及 Game 编译记录。本次不改游戏规则、镜头、导航或原生资产。

早期检查：42源文件、程序、父40文件和枪声精确一致，没有需要让出的用户引擎；
先冻结被否决音效及有关代码/旧视频清单。样本来源必须能确认物理声音及复用许可。
硬地脚步包含靴底接触/摩擦，静步更轻，跑步落地更实；换弹采用真实金属操作、
弹夹/枪机声音，跟原动画对齐，不加任意音高的电子点击或错用现代弹匣动作，
不在每次换弹末尾随意加“叮”。未使用的参考明确记录为未集成。

交付独立 WAV 试听及正常试玩入口，保持默认后台静音；核对格式、削波、换弹
时长/阶段、枪声身份，必要时做 UE 实际播放检查。用户在游戏内人工试听才是
真实感验收；计数、波形、许可都不能替代。期间不调用 OBS 录屏或视频重导出。

录屏问题：自动观察器 Move() 直接设置控制旋转，匍匐到达后也直接归零。
用旧画面/日志定位用户指出的动作；这是可能原因，不宣称普通鼠标也存在该问题。
后续要求正常输入驱动连续转身，已有动画支持时采用相应表现，不瞬间跳朝向，
也不靠剪辑隐藏；本次只登记，不实现、不录制。

停止条件：许可不明、候选带无法解释的背景人声/枪声、保护字节变化、解码/
编译/播放失败或重复 GPU 启动故障。不得继续拼合成音以凑真实感通过；缺真实
样本则明确报告缺口。保留失败；本次不提交/推送/SFTP/视频平台发布。

实施前时机补充：只提取旧原片检查，没有新录屏。换弹约4.13秒，旧声音把约
2.066秒的弹药提交当成动作结束，手还在继续运动；只替换 WAV 不能纠正语义。
另建精确42源副本，仅改非反射 ParisGameplayAV.cpp：实录多样本、分阶段机械
声音，角色离开换弹/死亡时停止对应换弹声。读取原角色时长/速率，不写弹药，
不改动画/自动观察器/头文件/构建/默认值/配置。枪声代码/处理保持精确。
其他未认可的合成布料/落地/倒地声可用明确标注的实录拟音替换；德国栓动步枪
不能错误使用 M1 的机构声，另找对应来源或如实报告缺口。听感/接触验收仍待人工。
