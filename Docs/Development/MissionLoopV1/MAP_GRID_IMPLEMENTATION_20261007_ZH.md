## 网格和黑白规则

内部使用UE厘米，每格1米，边界对齐整米。列号沿+X增加，行号沿-Y增加。格心坐标为`X = Xmin + (列 + 0.5) × 100`，`Y = Ymax - (行 + 0.5) × 100`。Z采用指定表面原生测得的站立脚底高度，不按楼层取整。导出脚底坐标与所选胶囊规格的独立实体中心。白格准入的是格心，不表示格内任意位置都可放置。

所有格默认黑色。白色要求精确导航表面、可步行的实际碰撞支撑和正式尺寸的竖直胶囊净空。黑格保留物理阻挡、无支撑、非城市／未知支撑、正式导航缺失、粗网格遗漏或未测原因。显示只用黑白，原因在点选面板解释；未知不能写成确定物理障碍。

同XY的多个表面全部保留，按实际高度排序用于查看，名称明确为叠置表面而非建筑楼层。跨表面连接另行保存。视图层不能证明楼层身份或楼梯可走。

分别记录完整临时测绘与正式保存导航。此前临时测绘扩展了范围，正式边界约420×420米；用户尚未选择最终可玩边界。工具允许查看正式导航之外的测绘城市，“当前游戏导航”筛选排除缺少精确正式导航证据的格。不能为获得白格直接保存扩大的导航边界。

## 原生几何采样

新增默认关闭、仅Editor使用的ParisGridSurveyV1辅助插件，保留已有两个测绘插件及二进制。在独立自有编辑器入口中，从未保存世界移除正式玩法对象，保留环境阻挡，按碰撞一致规则静止车辆，先导出正式导航，再按照已验证的自然解锁流程临时扩展并重建。

导航多边形内按格心采样，保留多边形引用。调用安装版本的`GetClosestPointOnPoly`、CharacterMovement原生地面查询及Pawn通道胶囊重叠。半径34厘米，半高采用已观察正式人物最大值96.23316厘米，台阶45厘米、坡度44.7651度。记录真实脚下组件与网格。静态采样不是实际移动，不修复或重跑此前失败的通行、跟队或战斗。

相邻准入格之间要求指定表面的有向导航连接及沿连接的碰撞净空。保留高差、台阶和缺失连接。一米分辨率可能漏掉的窄口继续黑色／未知，列入后续局部细化，不能静默连接；禁止沿对角线穿过墙角。

用途筛选提供几何候选：生成点要求声明的小队展开空间，任务点要求声明的局部操作空间，遭遇点要求接近空间与候选间实测视线。参数可调整，不是最终任务规则。面板分别显示几何条件和已有局部正式人物／跟队／战斗证据。用途白格不能证明未定义任务或完整小队行为已验收。

## 早期验收与停止条件

早期要求坐标往返误差低于0.01厘米，精确表面XY误差不超过0.01厘米，存在原生地面／支撑记录，叠层身份保留，合成障碍检查误白格0，源文件／旧辅助／703保护精确，自有进程正常退出且严格日志0。地形负面形成有原因的黑格，不等于全局API失败。

遇到进程占用、API／结构错误、必需表面身份缺失、正式玩法污染、环境碰撞／变换改变、受保护文件改变、导航锁超时、严格日志错误或期限到达时停止原生批次，保留独立入口并归档原因。不能放宽误差、移动失败点、改写未知或重跑失败身份求通过。不同测量修正需要日期补充和新身份；本方案不重测失败UE移动点。

完成条件为有限网格批次与审计、可用坐标选点工具、已查看黑白图、有界UE映射检查和完整缺口记录。本轮不包含逐格正式人物实走、编队修复、战斗平衡、最终布局、FPS或课程验收。

## 编译修正

native_v1因StrictIncludes下缺少紧凑JSON策略头文件而失败，原生采样0。已读ML012；新的native_v2显式包含安装版本头文件并使用float胶囊常量。不改变验收条件，仍先执行原道路／阻挡／叠层准入。

early_v1随后在采样前停止，安装版本编辑器Actor接口明确排除RF_Transient探针。native_v3新增包含临时对象的TActorIterator世界枚举与继承污染检查；early_v2仍要求一个探针、零控制器、零正式玩法对象。遭遇几何采用140厘米声明视线高度与5／10／15／20米候选距离的双向Visibility原生射线，不等于正式AI视觉或开枪事务验收。

early_v2隔离通过后在第一次地面查询处崩溃。native_v4显式把Editor探针移动组件绑定到胶囊，检查缓存角色与UpdatedComponent后才调用地面接口；early_v3保持道路／叠层／阻挡对照不变。正式保存导航的原生格间连接在临时扩展前采样，不通过导航边界矩形猜测连通性。每个入口冻结全部准备源码。
