## 网格与真实地图的关系

原始底图1008×1008，每格1米，覆盖生成导航的X/Y−50400至50400厘米。原始1位PNG每像素对应1米，X/Y使用相同比例；工具缩放只改变屏幕显示。+X向右，+Y向上，列c、行r从0开始：

`X=-50400+(c+0.5)*100`，`Y=50400-(r+0.5)*100`，单位厘米。

Z来自所选城市支撑的真实站立脚底高度，不从平面图猜测。同XY不同高度保留5个叠置表面序号；这不是楼层编号，不同格的相同序号也不代表同一楼层。草案同时保留脚底XYZ、来源范围、原生采样编号、多边形引用。参考实体中心使用最大胶囊半高96.23316厘米；实际放置要加对应角色自己的半高，德军为95.26415厘米。

黑格包括：碰撞阻挡、不能站立、导航/脚底高度不一致、代理或未准入支撑、正式导航未覆盖、用途空间/视线不足、其他选定连通组/表面、1米采样未覆盖的窄小区域，以及运行失败隔离。因此黑色表示当前筛选下阻挡或未准入，不代表所有黑格都物理不可走。白色证明格心和相应原生图条件；不保证整块1平方米任意位置或所有寻路到达偏移都可站立。

正式保存导航与完整临时测绘各保留自己的节点/连接，扩展只发生在临时测绘世界。正式白格直接来自正式导航原始记录。跨范围视线关联只允许同XY、同支撑、真实脚底差≤0.01厘米，两个原始导航高度仍保留。正式城市节点46,013个，扩展83,855个，真实位置关联45,650对；运行失败XY对应的2个节点已隔离。道路连通组正式632、扩展721，很多很小；非道路组保持黑色。这是保守网格图结果，不能据此断言城市道路全部物理断开。
