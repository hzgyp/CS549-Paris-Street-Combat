## 上下表面发现

原回执的 `same_xy_multiple_height_cells=99` 按1米 XY、25cm Z 取整，**不是楼层数**。单独后分析将 XY 精度收紧为1cm、上下最小间距设为193cm，得到 **43 处上下样本**：38 处两端均未连到玩家，三处只有上方连通，两处只有下方连通；本次粗采样**没有上下两端都连通的点**。这不能排除没采到的楼梯或中间表面。

例如世界 XY(−4000,6000)cm：下方 `sample_0950` 为 Z114.603cm，未连到玩家；上方 `sample_0951` 为 Z420.783cm，出去和返回查询完整。XY(5000,−950)cm 则下方110cm连通，上方510cm不连通。如果把两者直接压进同一个 XY 格子，会丢失连通信息。

因此导出采用 **XY + 表面高度／身份 + 有向连接**。某一选定区域只有确认排除叠置表面或明确分层后，才可以显示成单层。继续由 Unreal NavMesh 负责寻路，不增加自写 A* 或固定层高取整。
