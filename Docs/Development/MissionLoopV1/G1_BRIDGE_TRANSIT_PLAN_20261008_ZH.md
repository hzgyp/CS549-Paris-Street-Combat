# G1 过桥队形修正方案——2026年10月8日

中文审阅；同步英文：`G1_BRIDGE_TRANSIT_PLAN_20261008.md`。
本次已读 MI001、ML010、NI003 和 G1 实施方案。TravelV2 中玩家实际走完两段，
盟军在近岸距各自目标33.54／39.37厘米；过桥后停在桥前半段，距远岸目标
2437.88／3022.50厘米且 SquadFailed=true。原目标分别为
5396,-20463,306.23 和5491,-20121,266.23厘米。这是真实小队失败，
不是桥不存在或查询失败；原失败回执、轨迹和截图保留。

改变机制：新增仅用于本任务的窄桥纵队策略，不在原横向队形上重试偏移或时间。
对保存的 UE 导航查询同一 S→近岸→远岸路线，保留共享中心线；过桥时，两名存活
盟军沿玩家实测中心线进度后方450／700厘米，向原策略申请各自保留目标。
间距250厘米，满足原150厘米预约要求。继续使用原 PC_SquadRequestGoal、
原生 MoveTo、碰撞／RVO 和300厘米每秒，不逐帧摆放角色、不瞬移。给导航目标使用
脚底高度。不自制 A*，不虚构到达，不放宽标准。

仅新增的 BP_PCG1ControllerV1 通过原生任务接口覆盖 PC_UpdateSquad；桥区之外
调用原父实现。动作忙或现有战斗保持时调用原保持入口；视线、目标、开火／换弹／
伤害及守军逻辑保留。在 T1 保持窄队，玩家向东超过 X6500 且存活盟军真实抵达
远岸纵队目标后才恢复原队形。死亡盟军保留原释放处理，不复活。读档重新查询同一
已保存地图中心线，不接续旧世界对象、动作或轨迹。

所有权：仅新增插件源码／DLL 和自有控制器变化。先备份控制器，建立新的自有文件
准入回执，旧朝向回执作为历史保留。原地图、703项、位置、导航、模型、手指、骨架、
材质、已选表现及枪械规则不变。仅编译在隔离目录进行，安装／写资产等待引擎空闲。
不提交或推送。

早期验收：新进程原生路径完整且两岸端点准确；Ready 仍十秒零动作／资源变化／
移动及五个选用绑定。之后两名存活盟军均须在队长到达后25秒内，真实进入预约目标
55厘米范围；远岸结尾两人均须在 X5600 以东。改变任务策略后验证同一路线，
不重跑已停止的原横向队形。独立遭遇仍使用冻结 T1 组及原战斗。

首个坏查询、提前动作、保护变化、实体到达失败、资源增加或原生日志错误即停，
保留该次记录；本方案不允许第二组间距／侧向／位置／速度／时间扫描。
横向投影导致失败仍是待验证假设；新策略通过也不等于隔离了旧失败的所有原因。
