# 滚轮装备切换与左键投掷实施文档

状态：2026-10-11，实施前方案；基于未正式采用的 G1GrenadeModels20261011/source74 与 Game a927caa3…4eb59。正式 EnemyClear/source52 不覆盖。

## 操作与状态

按用户本轮要求，滚轮向下依次选择步枪、Mk II 手雷、烟雾弹，再回步枪；向上反向循环。装备栏显示三项及当前高亮，数量为零仍可选但不能准备，不会透传成步枪射击。G/Q 不再启动投掷。

步枪选中时左键、瞄准、R 仍交给原枪械；选中投掷物时隐藏显示枪、展示现有道具，左键按下播放已有拉引信准备动作。持续按住停在原 Hold，松开播放原投掷动作，在原提交时刻生成唯一弹体、扣一个库存。按住期间不启动引信，不扣库存；引信、碰撞轨迹、伤害、烟幕和感知沿用现有逻辑。投出动作结束后自动回步枪。

准备尚未松手时，Esc 播放原 Cancel 并回步枪；滚轮取消本次准备并选择下一项，取消动画结束前不接受另一投掷。取消后旧左键松开只清除状态；必须重新按下才能开枪或拉引信。松手已进入 Release 后不允许取消或切换，避免撤销已承诺投掷／重复扣数。步枪左键按住时切换也先释放旧枪械输入，禁止新装备继承旧按压。

菜单、存档弹窗、死亡序列先处理输入，滚轮及左键不能穿透。失去窗口焦点时取消尚未释放的准备，不自动投掷。重开／读档回到步枪；装备选择和按压属于临时会话，不写新存档字段。已有全灭敌军、圈内 E、schema、资源、checksum、写盘及读回验证不变。

## 范围与保护

只修改装备会话、装备输入／显示、操作帮助和实际输入测试夹具。现有 Mk II／烟雾弹／地雷模型、原人物及骨骼／手指／挂接位置、原投掷 Start／Hold／Far／Cancel 动作、枪械绑定和内部逻辑、存档代码、AI／导航／碰撞原件保持。选中时沿用现有手部姿态，不把本轮视为新握姿或全动作验收。统一试玩放 tmp 独立目录、独立 UserDir；不自动正式采用、发布或清理。
