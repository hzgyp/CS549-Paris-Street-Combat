# 正式角色与小队地图验证流程

2026年10月7日，实施与执行前形成。[英文原文](FORMAL_ROLE_SQUAD_TEST_PLAN_20261007.md)同步。用户授权验证正式玩家、盟军、德军在地图上的通行、小队同时移动及双方遭遇。**所有坐标仅为临时测试刺激，不确定最终出生点、任务点、遭遇地点、巡逻路线或可玩边界。**

## 基线与保护

采用正式9ff地图、当前703项保护及已授权三项本地后坐力DLL增量。执行前已读AGENTS、HANDOFF、失败索引、纯地图最终结果与审计、NI002、NI003及ML001–ML007。保留模型、骨架、权重、手指、正式持枪绑定、武器、原动作和枪械事务、控制器、行为树、地图、导航设置与Catalog。不保存正式资产、不创作Blueprint、不提交或发布。

纯地图测试曾在未保存副本中扩大导航范围。本轮先使用**正式地图实际保存的导航**，不重建、不扩范围。纯地图通过点超出正式导航覆盖时，单列覆盖负面，不能静默扩导航使测试通过。继续保留XYZ和真实表面身份。

现有跟随／预留逻辑只接受TeamId0、两个名额；德军采用警戒／搜索／交战。因此德军三人验证的是同时通行与敌对交互，不冒充已实现的德军领队跟随或三槽队形，也不在验证中新增该能力。

## 冻结清单

进入前ML008纠正：V1仅按包归属选中了Landscape承托；UE／物理尝试均为0。保留V1清单及原计划／源码哈希。V2排除轨迹中的Landscape承托，并要求采样中确有Road组件；原生、资源、碰撞、到达门槛不变。
V2又在进入UE前发现首候选只有四个认证站立点、需要五个。V3把已声明起终点／领队容量纳入离线准入，保留候选拒绝原因，500cm／30cm／100cm场地门槛不变；不重试物理放置、不扩大范围。

进入UE前，在私有空间从已完成纯地图证据形成认证清单。确定性选择双向已通过、承托来自巴黎环境的表面，排除Engine BasicShapes及外围代理；处于已记录正式导航范围内并留边距。选平街、窄口或转折、高差三类，优先路长4–20米，记录规则、原case及哈希。两盟军与三德军的额外站立点取自已通过观察，保持彼此区分。不猜远处停车点、不随机扫偏移、不复用失败队形目标，也不在失败后换点求通过。

主单人清单36段：六名原正式人物×三类路线×双向。另有早期六段控制：正式玩家、一盟军、一德军在平街各往返；控制不增加主分母。

小队清单包括两盟军原生跟随六次、三德军同时通行六次，以及平街／转折两次对向交通。盟军使用真实原生跟随和队形预留，玩家方向与临时领队目的地只一次设定。德军通行隔离决策策略、同时发起原生路径，不虚构三槽协调器。

三次全新有限遭遇分别覆盖平街、转折、高差。平街／转折采用两盟军对三德军；高差若冻结站立点无法容纳五人，则明确标注每方一人。现有原生感知、选敌、追击／警戒／搜索与战斗保持权威。不用Python伪造看见、写Blackboard、指定敌人、请求射击或逐帧驱动NPC。

## 早期验收与实测标准

开局需五名正式控制器和独立Blackboard、两盟军／三德军正式持枪绑定、原玩家FP初始化、100HP／2已装／16储备／0枪、原胶囊与移动参数、唯一协调器与友伤策略。必须先隐藏启动，不能消耗后再关闭战斗伪称准入。

每项仅一次声明初始放置，正常落稳后检查无观测阻挡重叠、步行、CurrentFloor可步行、XY及胶囊脚底均距认证表面≤35cm。实际脚底与世界导航／原Agent查询需完整非部分路径。单人及交通原生请求使用30cm到达半径、不叠胶囊半径，必须匹配编号／控制器／SUCCESS、Idle、XY≤35cm、脚底≤35cm及步行落地。原速度／台阶／坡度／重力／RVO不改。期限max(12秒, 路长/当前最大速度×2+10秒)。

盟军队形还需两人不同保留名额、有效预约，每个真实身体距其实际HeldGoal≤原55cm。记录原始／投影目标与地面；投影成功或Arrived标志均不单独算通过。记录队员间距、停滞、重规划和最终身体位置，不关碰撞／RVO、不放宽门槛消除拥堵。

遭遇准入后观察30游戏秒，记录最初遮挡与后续真实LOS、原生感知敌人对象／HasVisibleTarget、实际接近轨迹、决策／动作阶段、枪数／结果、HP与弹药守恒、死亡及死后停止。功能遭遇要求双方都发现真实对手、通过原事务射击并有敌对伤害；只向被动玩家开枪不算盟德交互。未碰面保留负面。交战中不传送、补弹、复活或隐藏死亡人员。

使用正常时间和渲染，记录采样节奏但不升格FPS。保存并检查代表性的未暂停原图；不解锁已停止的完整动作／接触／近墙验收。

## 停止条件与交付

API／ensure／日志错误、保护变化、绑定或资源错误、加载重入、车位移、原身份缺失或玩家丢失占有，全局停止该入口并保留失败原回执。物理拒绝停止该项并记负面，只继续清单中其他独立项；不扫偏移／角度／时间／容差、不自动修AI。不同机制需要新的有界文档与早期门槛，早期诊断失败不得进入广泛测试。

编译／启动前查实际进程，保留其他任务或用户编辑器。恢复临时编辑器设置、正常结束自有PIE；每入口启动器15分钟预算，硬期限只关闭自有进程且如实记失败。

新增源码位于Tools/Integration/FormalMapVerificationV1及独立Editor-only插件；清单、原始JSON、日志、编译产物、图片与商业地图衍生图留在私有Evidence/FormalMapVerificationV1及tmp/formal-map-v1。独立审计核对分母、原生完成、真实到达、资源、绑定、正常退出／日志及当前703保护。最终中英文结果分开正式导航覆盖、单人、小队、德军交通、敌对碰面、看见与造成伤害；任何测试坐标均不升级成任务布局。
