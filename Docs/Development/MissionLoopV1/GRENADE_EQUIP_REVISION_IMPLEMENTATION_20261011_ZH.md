# 手持投掷物与库存轮换修订实施文档

2026-10-11，实施前。父版source75／Game332756d0…b15695已被本轮人工试玩否决，正式source52仍保持。模型、原枪械握姿／手指参数、枪械资源逻辑、全灭敌军存档规则均保护。

## 已读失败与本轮改变

MI024要求等正式FP Initialized并在原显示更新后隐藏枪；MI033／MI043要求真实渲染帧与已处理输入见证；MI044要求情境提示失效即移除；MI045记录本次人工否决。源75的Ready固定持枪源及固定三槽轮换已核实。本轮不再把道具Actor存在、控制器输入通过或原低Hold限制视为手持动作／可见性通过。

资产索引先查anim-rifle-animset-pro，已有InPlace Rifle_Grenade_Throw_Loop／Start／Far／Cancel；d059-rifle-pro查询无额外手雷动作。原配置已AlwaysCook整个InPlace目录，可在独立Game中检验加载与骨架兼容，不重烘焙或写native。MkII2733三角与烟雾7562三角、8个运行文件保持，先判断姿势／挂接遮挡，不重建模型。

## 状态和视觉

选中手雷或烟雾弹进入真实装备就绪：显示原人物网格，以兼容的手雷Loop作为临时FP动作源，隐藏枪，展示当前道具。原身体ActionState保持Ready，移动与存档不新增门槛。左键按下进入已有Start，长按使用Loop，松开进入原Far；原唯一提交／扣数／3.5秒引信／轨迹／伤害／烟幕保持。取消／切枪／死亡／读档／重开清理临时源，回到既有步枪分支和原握姿参数。

临时FP源使用原骨架与动作，不改模型／权重／手指常量。装备动作与原持枪使用不同的显示状态，避免Ready强制覆盖为端枪。需要显示取景适配时，仅按原已验证的持枪手位置和新动作的实际手位置推导一次显示根平移，保留原镜头／身体／骨长；投掷物按掌指及指根构成的手持坐标系挂接，不扫偏移、角度或放大模型。实际MkII／烟雾图须清楚显示外壳；视图失败停止并记录测量，不能用哈希代替实图。

## 可用装备轮换

步枪始终可选；手雷仅Frag>0，烟雾仅Smoke>0。正反滚轮搜索下一个可用项，同一UE轮格只切一次。若只剩步枪，滚轮立即返回，不发动作切换／隐藏枪／创建道具／影响左键状态。投出最后一枚后回枪，下一轮自动跳过已耗尽类型；两种都耗尽后保持枪。HUD可保留灰色0数量信息，但它们不是轮换中的装备槽。

## 顺序、验收与停止

1. 冻结父75、普通100文件、旧用户档、Catalog和1754原生；建立独立tmp候选，保留人工失败身份。
2. 先做就绪动作源／显示状态与库存轮换，测试真实加载、正常镜头的Frag和Smoke就绪／长按画面、回枪原Alpha／指姿，以及真实耗尽后的双向轮换。道具不可见则不进入交付。
3. 通过早期门槛后，最终同一Game回归投掷／烟幕／原枪械／地雷补给／全灭保存／新旧档恢复／菜单暂停／死亡重开。保存代码／原NPC及导航／镜头保持；不新增NPC压力或擅自正式采用。
4. 更新帮助与选择器，记录真实图／哈希／限制，交付tmp统一普通入口，无探针或自动操作。现有UE Editors保持开启。

停止条件：动作仍由持枪源覆盖、任一道具不可见、零库存被轮到、全耗尽仍变空手、回枪原握姿／资源／保存保护漂移或实际Game异常退出。失败源和实图保留；不放宽这些门槛。

v1原枪握点锚导致Frag投影仅47.338%在屏内，停在早期门槛。新增有界投掷物显示布局：实际最大模型轴长＋当前FOV／视口解算24%画面高度及(0.68,0.70)中心，只改临时FP显示根，不改模型尺寸、身体、原镜头或枪械框架。先保存真实就绪图再查投影；维持0.75屏内比例门槛及人工实图复看，旧源／Game／诊断保持。

v3只读显隐诊断：v2图中的Frag仍不能清楚辨认，先保留姿势／挂接／镜头，在独立夹具短暂隐藏手部渲染并保留道具取图，确认遮挡来源后才改挂接。普通玩法不隐藏手、原0.25秒混合与门槛不变，回枪见证等待实际Alpha完成。
