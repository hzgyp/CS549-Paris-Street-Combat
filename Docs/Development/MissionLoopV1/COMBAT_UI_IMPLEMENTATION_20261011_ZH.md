## 界面与交互合同

### 统一作战菜单

Esc 从普通玩法打开暂停菜单，Tab 直接进入同一菜单的任务/状态页；再次 Tab 或 Esc 返回。顶部为任务、人物与小队、操作帮助、设置，左侧为继续、读取检查点、重新开始、退出。无有效存档时读取禁用并解释原因；读档、重开、退出须鼠标/Enter明确确认，Esc取消。Ready/Lost 的原开始/重开/读档菜单继续可用，增加帮助入口。

本轮 UI 标签沿用当前英文，正文使用现有已cook字体以保证独立 Game 可用，标题延续现有象牙色/黄铜/军绿。首版设置实现简洁/详细提示与 HUD 比例；中英切换、自定义按键属于后续独立扩展，本轮不显示不能生效的开关。

完整菜单使用 UE 单人暂停，角色、AI、已释放弹体/引信、烟幕寿命与拆除进度不在阅读时继续推进；关闭后恢复先前状态，不重置寿命或补资源。UI继续接收鼠标与键盘。菜单只能暂停自己创建的暂停，不能解除其他来源暂停。

Esc 优先交给现有投掷取消、拆除取消、checkpoint窗口关闭；此次取消后不同时打开菜单。准备投掷/正在拆除时 Tab 提示先结束当前交互，不重复投掷或完成拆除。正在同步保存/等待结果窗口时不另开暂停菜单，保持实际保存窗口与 readback 的原流程。

菜单内的开火、换弹、装备、E 和快捷存读档不泄漏到玩法；松开/失去焦点/菜单进入退出处理防止持续移动、误射击、卡住按键。F6/F9 在普通游戏也进入对应确认 UI，确认后调用原函数；E 保存与原圈内确认规则保持，不新增随处保存按钮。

### 任务、人物与帮助

任务页直接读取原 Phase/LivingDefenders/CheckpointUnlocked，展示清除进度、G1 位置/距离、存档是否有效及路线提示。只消灭三守军即可完成；不增加占领计时、盟军到达、姿态或拆雷门槛。任务完成不写成区域安全。

人物与小队页只读实际玩家及 Ally1/Ally2：血量、存活/姿态/动作、武器与弹药、手雷/烟库存、盟军编号/距离/实际行动状态。没有新建军衔、技能树、治疗/指挥/布雷功能，不显示未发现敌人或地雷位置。

帮助按移动、武器、战术装备、交互与保存分类，完整包含 WASD/鼠标、Shift/Alt/Space/Ctrl/Z、左键/R、G/Q、E、Esc/Tab、F6/F9。明确 G/Q 按住准备松开投掷，地雷两米内有效瞄准 hold E两秒，补给只增加有限备用弹药，匍匐移动受现有地形支撑条件限制、当前没有完整ADS。

### 战斗 HUD 与情境提示

保留原准星、血量/装填/备用弹药、玩家中心小地图和盟军标识，新增带按键帽与数量的两种装备图示、菜单入口提示及实际姿态。任务标题与当前清除进度始终一致。

只显示当前最相关的可用操作，遵循圈内保存优先和原装备目标检测：投掷准备、拆除进度、补给剩余/耗尽、金圈E保存。地雷位置继续由原发现/可见/烟幕遮挡函数决定；距离不足仅在原已发现且实际可见的范围提示，不读取全部陷阱坐标泄露位置。

第一次遇到投掷准备、地雷拆除、补给和已开放保存时出现一条短引导，帮助页始终可查。会话内引导与视觉偏好不进入游戏存档，不修改已验证的保存载荷；设置变化必须有实际显示效果。

## 实施和验收顺序

1. 冻结父63文件、父 Game/正常包、1754 native、Catalog、原正常用户档；创建新候选，先写本文再改源码。
2. 接入独立 UI 会话，先验证 Esc/Tab 开关、真正暂停、鼠标/键盘选择和输入复位；早期门槛通过才扩展页与HUD。
3. 完成四页、危险操作确认、帮助完整性、装备图示/数量、情境提示和首次引导；不改原机制。
4. 在同一匹配 Game 实测暂停时移动/AI/弹体引信/烟寿命不推进、关闭后继续；投掷/拆除 Esc 优先、菜单不误射击，快捷读档/重开确认和取消。
5. 实际截取任务/人物/帮助/设置、战斗提示，核对1080p及较小分辨率布局；数值与实际资源对照，禁用和失败反馈可读。
6. 同一 Game 回归原枪械/装备/烟幕/地雷/补给、菜单、三敌清场、真实保存/new-process恢复、旧载荷兼容、死亡与重开；保持负向校验仍拒绝。测试夹具与自然人工玩法分开记录。
7. 精确源码快照、Game/包哈希和保护审计闭合后给一个无自动输入/探针/AI暂停的正常试玩入口。等待人工选定，不自动替换正式基线、commit/push、SFTP、录像或清理旧证据。

停止条件：父保护漂移、反射/cooked不兼容、暂停时危险继续计时或关闭菜单补资源、误射/卡输入、UI泄露隐藏装置、清场门槛退回旧规则、存档字节/校验语义变更或正常入口带测试夹具。失败身份、源/编译/日志/图片原样保留；采用明确的新候选修订，不反复覆盖失败源。
