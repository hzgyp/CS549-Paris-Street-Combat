## 交互

1. 入圈仍只询问，不自动存档。E 明确确认后收起询问栏；条件未满足时显示 WAITING TO SAVE 窗口，说明需要站立/停止/等待小队，玩家仍可松开移动键、站起或离圈。ESC 取消；30 秒仍不满足则显示未保存原因及重试按钮。
2. 条件满足后显示 SAVING CHECKPOINT，至少提交一帧该窗口绘制再调用原同步事务；不人为增加保存耗时，不伪造百分比，不把等待称为已经写入。写入前仍由原保存函数复核全部条件。
3. 原写入和完整回读校验成功才显示 CHECKPOINT SAVED 窗口及 OK 按钮，Enter/E/Esc 或鼠标确认；本次进圈 E SAVE / ESC LATER 继续隐藏，重复 E 不写第二次。离圈再进入可明确确认下一次保存。
4. 原事务失败显示 CHECKPOINT NOT SAVED 窗口及 RETRY / CANCEL；保留原槽，不报成功。重试只再次请求原事务。等待/保存过程中重复 E 不增加请求；等待可取消，事务开始后不假装可中断同步写入。
5. 成功/失败/写入窗口吞掉射击与玩法按下事件，键松开事件仍送回原输入，防止粘键。等待不锁住站立/停止输入。窗口关闭恢复正常输入；F9/F6 换世界自然销毁全部运行状态，不写入存档结构。
