## 实施顺序

1. **动作接入。** BeginPlay前接入既有V6子类，继承同一把原枪、相机和显示归属；先核对
   模型／材质／缩放／相机／资源一致。WASD步行150、Shift跑300、Alt静步65、Space跳跃、
   Ctrl蹲120、Z匍匐60cm/s。复用原生Blueprint动作与身体碰撞逻辑，不做新动画／姿态
   驱动；保留站姿开火换弹、匍匐只限安全前后移动，不偷偷启用未验收的趴姿射击／侧移／
   转向。正式FP手与来源绑定保留。打包后的实际按下与释放需重测，不能套用旧V6结果。
2. **小队间距。** 玩家路径距离足够后，才允许对应队员进入既有跟随路线；此前保持
   原地，不把两人都吸向玩家起点。先观察静止开局，再走原过桥门槛。若原出生地本身
   仍不合适，再按测绘合法点另做入场检查，不盲移坐标。
3. **存档圈。** 三个固定G1守卫均记录真实死亡后，在已测G1锚点出现半径180cm地面圈
   与小地图标记。原过河／攻占条件仍决定Won；胜利停止NPC战斗，但保留活玩家移动
   与转向。进入圈询问“Save checkpoint? [E] Save [Esc] Later”，不自动存档。E只调用
   一次原安全存档／日志事务；不安全时显示原拒绝原因，可等候重试。离开／取消后，下次
   进入才重新询问。F5只申请显示问题，不绕过区域／确认；F9读档；F6重开，取消冲突的Ctrl+R。
   新配置／槽位V5，旧配置按原指纹校验拒绝。仅站立／落地／静止时保存，不能
   保存未支持的匍匐／空中姿态或补造资源。
4. **HUD。** 左上紧凑任务，左下血条与小队状态，右下大号当前装弹／后备弹药、八发
   容量图示与枪械名称。只读取真实Health／LoadedAmmo／ReserveAmmo／Capacity／ActionState。
   若显示“满装等效数”，按备弹÷容量计算并列余弹，不虚构独立弹夹库存。低血／缺弹同时
   用颜色、形状与文字提示；存档问题和状态只在需要时出现，按窗口缩放保留安全边距。
5. **小地图。** 按要求放右上，沿现有地图XY约定固定朝北，显示玩家朝向、存活盟军、
   当前任务与已解锁存档圈。由核验过的G1已保存NavMesh多边形生成等比例静态底图，
   区分通行／阻挡；这是已测地面范围，不是全城市分层测绘。纹理只读一次，标记5Hz
   更新，不增加每帧场景摄像机。敌人必须处于玩家实际视野且无遮挡才标注，不能透墙
   把全部德军坐标展示出来。核对XY、四角、朝向与真实地图映射。
