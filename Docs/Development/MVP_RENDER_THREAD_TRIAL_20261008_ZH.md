# 有界渲染线程性能试验

2026年10月8日。[英文原稿](MVP_RENDER_THREAD_TRIAL_20261008.md)。已读Failures/README、
MI004／MI005及本次收尾／输入诊断计划。原资产、758源码、359选中原生文件与703项保护。

navrepair_v1三份完整玩家路线CSV实测36.84／36.05／36.08FPS，未达60目标。渲染线程
约26ms、GPU约11ms，存在硬件光追场景收集工作，提示CPU／场景工作负担，但不证明
关硬件光追能达标。不使用缺尾部的cohort前缀。安装UE5.8的D3D12Adapter.cpp支持启动
-noraytracing；原DefaultEngine.ini开启光追。

当前小队测试完成后，用独立新运行身份只改变-noraytracing。保留实际1920x1080、
High／十项sg2、100%屏幕比例、1536MiB纹理池、VSync0／不限帧、城市／模型／材质／
动作／AI／目标及原门槛。同一个新观察器构建和原生自然完成输入测三次；仅当同版
RT开启的CSV尾部与完整小队流程均有效时才作为配对对比，旧玩家单独通过只作背景。
不录像、不同时跑哈希／打包任务、不随意删卡顿。

早期验收：无占用原生写入者，输入／程序哈希精确，实际观察器／Ready／分辨率／
画质／纹理池及硬件RT禁用已确认，查看Ready实图，不能只根据参数认定已生效。
三次有界完整采样报告帧数、时间、均值／中位数／p95／最大值、CPU／GPU／内存及实际
60FPS结果，包括未达标。软件渲染路径视觉差异只是声明的试验配置，不自动正式采用。

首个玩法／路径／小队／错误／哈希失败、溢出、无效采样或原界限即停。不扫描其他
设置／分辨率／纹理池、不悄悄降纹理／画质、不用短诊断冒充最终通过。当前小队测试
若失败，先保留原因、处理功能，再做性能试验。
