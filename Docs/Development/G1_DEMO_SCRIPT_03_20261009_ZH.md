对同一任务路线/负载进行三次完整无录屏测量。保留不裁剪的原生帧耗时CSV，记录人数变化、
平均/p95耗时、卡顿、导航停滞。另录12秒OBS观察片段，区分录屏开销、瞬时HUD统计与
独立测量结果。历史本机硬件为i9-12900F/RTX3080 10GB/32GB，录制时须重新核对。

如进行递增人数压力专项，应先单独准入当前版本的场地、装备、活跃AI和测试入口，
再沿用预声明6/12/18名初始角色、上限18的安排。首个性能/导航/严格错误即停止；
若六人初始任务平均耗时超过16.67ms，展示实际限制，不进入12/18。高负载仍算未测。
六人通过但缺少准入专项入口，也不能自动继续加人。本稿不授权开发该入口；
独立/协调目标的匹配比较仍是另一项验收。

未准备好测量时，审查片只放SRT中明确“待完成”的说明；这不算可提交的压力/视频通过。
