## 为什么现在停止这条尝试

本次三个样本否定了“把原整个人物连枪刚性搬近/偏右，就能让非手臂部分自然出画”的假设：保留整体关系也把头颈、衣物带进镜头。这不证明所有原姿态第一人称表示都不可能。

按实施文档的停止条件，不选遮挡最少的一张，不继续扫偏移，不重新加前臂胶囊裁切，也不扩展运动或保存地图。下一次实施前必须设计不同机制：评估兼容现有持枪内容，或有界的拥有者视图适配，让非手臂可见性与连续手臂呈现分别得到处理；继续保护原资产、手指、源动作、相机和枪械事务。这是下一阶段的设计要求，不是重启失败人物/手指路线或采购的权限。先产生自检可用的静止画面，再请用户判断持枪风格。
