## 2. 为什么V12还缺这一层

M1对比中，枪托外缘、握持颈部和木钢交界处有不规则浅色磨耗，平面上有少量明确划痕；不是单纯把整枪调亮。V12只选了较纯净的M1木纹区域，避免抄到螺丝、刻线、源枪结构。它保留了底材，却没有把“德军这把枪哪些地方更容易磨”的空间关系重新建立起来；镜像采样还会复用痕迹。

因此本轮不是再换木纹或整张提高分辨率，而是在原木纹上增加**按目标表面定位的使用痕迹**。M1提供色调和伤痕形态参考，德军自身的表面决定位置。源枪的法线、阴影和边缘位置不能整片拉过来。

## 3. 磨损位置与强弱

| 木制区域 | 要呈现的痕迹 | 要避免 |
| --- | --- | --- |
| 枪托后端外缘、下角，木材靠托底板边界 | 短而断续的浅棕露木、几处小磕擦；比中央明显 | 一圈均匀白描边；磨损贴到金属底板上 |
| 枪托上脊、下缘和外凸肩部 | 狭窄、不连续的磨耗斑块，随真实凸边走 | 所有凸面全亮；连成长条光带 |
| 握持颈部/过渡处 | 轻度油色变深、表面局部抛光，夹少量擦痕 | 用大块亮黄掉漆取代手握抛光 |
| 前护木常握持的两侧与凸缘 | 少量顺长向或斜向擦划，露木集中在突出部位 | 内部凹槽、被钢箍盖住的面同样重磨 |
| 木钢接缝旁的外露木唇、钢箍邻近外侧 | 少量碰擦斑，强度低于枪托易碰的边角 | 整个交界都描边；木色划痕跨到钢上 |
| 枪托宽阔平面 | 保留大部分完整木纹，少量长短不一的划痕 | 两侧镜像一模一样；满屏裂纹/噪点 |

左右侧、上方、下方都覆盖，但痕迹不对称。凹陷/遮蔽面保持相对完整，不能用曲率一个数决定全部磨损。

### 枪管及相邻外露钢件

| 钢件区域 | 要呈现的痕迹 | 要避免 |
| --- | --- | --- |
| 外露枪管主体 | 克制的不规则深浅色差、少量细长/斜向擦痕，局部粗糙度变化 | 均匀新亮管、整段磨成银白、重复环纹 |
| 枪口外缘、前准星外凸边 | 少量发蓝表面磨耗，露出暗灰钢；强度略高于平整枪管 | 整圈白边、改内膛/枪口几何、夸张积炭或烧色 |
| 钢箍、托底板外角与护圈外凸面 | 稀疏边角摩擦和小擦伤，与附近木材的使用程度呼应 | 木头已很旧而五金全部崭新；所有边同样亮 |
| 外露机匣/枪栓柄常触碰表面 | 少量接触抛光、擦痕与暗色污迹，保留原结构细节 | 重画结构法线、改机械形状或满身锈斑 |
| 钢件凹隙/接缝与遮蔽区 | 少量局部暗色油污/灰尘；被护木盖住的枪管不加重磨 | 全枪黑泥、凹隙反而强烈露亮钢、木钢痕迹串色 |

整体风格是“维护过、使用过的旧枪”，不是废弃锈枪。木材露木可较明显，钢材磨耗通常更细、更克制；匹配的是整体使用程度，不是统一亮度。

## 4. 三层材质，而不是一层白线

1. **木纹底层**：保留V12已有木纹、主色和细法线，不把整块木托变灰或变黄。
2. **划痕层**：少量不等长、略弯/断续的细划；以顺木纹和轻微斜向为主，少量横擦。浅层划痕只改变颜色/粗糙度，较明确的划伤加弱凹向法线；不挖几何沟槽。
3. **边缘磨耗层**：在确定的外露凸边和碰擦区，局部磨掉深色表面，露出较浅的木色；边界破碎且渐变，不是均匀描边。握持抛光与露木分开做，前者可以略暗、略滑，后者通常较干、较粗糙。

BaseColor、Roughness、Normal使用同一对应遮罩，避免只有亮线没有材质变化。木材Metallic始终为0；不把浅色露木做成金属。法线贴图改变不等于网格法线被修改，验证时分别记录。

建议起始尺寸（仅创作初值，非实际测试结果）：较明确划痕长约10–40毫米、宽约0.8–1.5毫米；少量更宽擦痕和小斑块补充。边缘磨耗约1–4毫米宽且断续，不能全枪同宽。先少后补，细到普通展示看不见的痕迹不再耗时间。最终以与M1同尺度的画面为准，不用划痕数量或磨损面积百分比当作外观验收。

### 钢材响应

保留深灰/发蓝钢底色和原结构法线；局部表面磨耗略浅、反射响应略不同，擦伤不涂纯白。细划痕与暗色污迹分别使用定位遮罩，不能把木材露木遮罩跨材质使用。露出的钢仍为金属；确实模拟污垢覆盖的少量区域才调整覆盖层金属响应，不能全枪降低Metallic伪装旧化。粗糙度按磨光与污迹分别变化，不是一律提高/降低。必要的新细划痕只叠加微法线，不能抹掉成品底子的结构法线。不要为了“看起来旧”添加大锈斑、深凹坑、夸张枪口烟黑或彩虹烧蓝。

## 5. 实现方法与先行检查

使用 blender-modeling-workflow，只重开阶段5–7（贴图/呈现/导出），不重开已经认可的形体阶段。

### P0：确认贴图可以按位置区分

已读源码：V12给木托与上护木共享材质；V10 loft侧面用纵向U/环周V，端面另用圆形UV。因此不同部件、端面与侧面存在覆盖同一纹理区域的风险，**具体冲突须执行时检查，当前未做实际UV重叠测试**。

- 先分别记录 `Wood_ContinuousStock` 与 `Wood_UpperHandguard` 的面/UV范围、覆盖重叠及接缝。
- 木托与上护木在候选中各用自己的磨损贴图，原UV不动，避免同一划痕重复落到两个物件。
- 若端面与侧面UV冲突：只在派生文件为已存在的端面指定独立材质，必要时端面各自隔离；不切网格、不重展UV、不删除面。端面与侧面颜色必须一致。
- 若这些有限材质隔离仍不能正确表达位置，停止并记录，不平均冲突 texel、不重新切网格来强行过关。
- 钢件也先记录真实材质/UV复用关系，尤其 `Barrel_Donor_Tapered`、`Muzzle_Donor_Insert`、钢箍/底板/护圈及机匣/枪栓柄。按对象/已有面索引限定材质遮罩；需要不同位置旧化而共用UV时，只分离派生材质/贴图，不改钢件UV或拓扑。防止枪口擦伤重复出现在枪管中段、准星与护圈上。

### P1：先证明一个真实边缘

在真实木材网格上，选定枪托后下角/托底板旁外露边缘和相邻平面，记录部件与面索引。根据实际表面邻接、凸/凹关系和距离生成宽缓候选遮罩，再人工限定到表中合理碰擦区域。曲率仅作辅助：不把每条三角边、UV边、凹槽或材质边界当成磨损边。

先出无光照遮罩图/颜色图及固定棚灯近景，确认磨损真的附着于这个边缘；检查反面/底面及接缝。**最早失败条件**：平面整片变浅、金属被染色、出现网格线、错误复制到上护木、接缝白线、遮罩与凸边分离。出现这些情况不继续加划痕。

钢材再做一个独立早期证明：外露枪管一小段加少量擦痕/色差，并检查枪口外缘或钢箍凸边。确认真正有旧化但不会整管发白、形成环形接缝、染到木托或丢失结构法线；不通过不扩展其余钢件。这不是另开枪形重做任务。

### P2：完成木材与外露钢件的有限旧化

小区域通过后才铺到其余指定区域。用同一机制，但左右不对称；划痕以实际表面距离/毫米尺度定位，不能用整张UV上均匀随机撒线。选用现有M1可用的纯擦伤片段时，先检视D/N/ORM，去掉源枪结构性法线和位置AO；没有干净片段就用少量可重复的曲线遮罩，不调用云端重画纹理。

优先输出两套木材2048²贴图，目的是让新增划痕获得足够像素，而不是声称把原723×434木纹片段放大就生成了新细节。外露钢件按上表增加少量定位磨耗/擦痕/污迹；优先保留其现有分辨率，必要隔离材质不能无条件为每件加一套高分辨率图。原钢材结构法线作为只读底层保留，若叠加微法线需记录合成方法。未列入旧化范围的贴图不变。输出记录图数、分辨率、材质槽/GLB primitives与文件体积；避免无意义4K/多层实时复杂材质。

将局部遮罩与D/ORM/切线Normal烘焙为常规图片。烘焙只包含材质与表面细节，不含棚灯高光/阴影；GLB不能依赖Blender Pointiness等节点才能显示。处理法线方向、UV镜像和边缘扩展，保留足够纹理padding并检查缩小/mipmap级别的白边。所有参数/定位/随机种子（若用）写入独立可重跑脚本。

### P3：一次对比，必要时一次纠正

以同灯光/相机/真实尺寸对比M1、V12和V13：整枪、木托、握持过渡、护木、外露枪管/枪口和机匣钢件；补看左右、顶部、底部。既看近景，也看与上轮相同的整枪距离，不靠换灯/降曝光隐藏过亮磨损。用无光照颜色及另一侧光方向确认浅色区域来自纹理，不是固定反光假象。整枪验收必须同时看钢木旧化协调，不能分别看两张漂亮近景就通过。

允许最多一次针对明确问题的材质纠正，例如太白、划痕太密、宽度过大或接缝问题；仍失败就保留V13为未选中试验，停止该方法，V12不变。不得无限扫噪声/曲率阈值、继续抠微观细节。

### P4：导出后再验收

应用导出修改器（`export_apply=True`）、贴图内嵌，干净GLB导入后检查24部件/24,466三角面、尺寸、UV、网格法线、新增木/钢材贴图及端面绑定。钢材底层结构法线和范围外贴图哈希不变；允许变化的颜色/ORM及微法线另列差异，不继续宣称“全部钢材贴图不变”。与V12逐项比较，严格区分允许的贴图/材质差异和禁止的形体差异；UV/网格法线采用现有审计声明容差，不伪称编码完全相同。

重新查看实际GLB六方向及木托/护木、枪管/枪口近景。干净脚本重跑与导出数值/图片字节检查；整文件SHA不同时如实记录，不能虚构原因或把图片一样当作字节一样。最终给用户同条件M1/V13大图，人工确认后结束外观精修。

## 6. 外观验收及停止标准

- 普通整枪距离：一眼能读出“用过的木枪托”，但仍然先看到枪形和木纹，不是白色破损花纹。
- 木托近景：能找到几处明确划痕；露木重点位于真实边缘、凸起或碰擦位置，不是均匀铺满。
- 护木/反面/底面：同一质量层次，痕迹不镜像复制，凹处和被盖住的区域不莫名重磨。
- 旋转灯光后磨损仍存在；没有网格线、UV缝白圈、浮起贴片、划痕穿过金属或过强法线起伏。
- 整枪不能呈现“木托很旧、枪管很新”：枪管、钢箍与相邻外露钢件有克制的使用痕迹，木钢协调而不是全部磨成同一浅色。
- 当前枪形、尺度、木纹底材、钢材身份和原钢件结构法线保留。数值通过只证明导出/保护，不自动通过视觉。
- **用户认可该外观即停止**，不再细化螺丝、刻字、锈迹、凹坑或枪栓机械。可称普通游戏道具的外观候选，不提前声称UE运行/动作/授权验收完成。
