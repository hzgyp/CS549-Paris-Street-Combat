NI001 要求实际枪碰撞和原换弹身份；GP010 不能用 CDO 替代游戏实例；AN008
已停止的握姿和完整动作试验保持停止。AI 功能通过不等于接触、后坐力或动作通过。

CombatV2 原来依赖测试脚本的一次性启用。新增原生行为树启动服务等待对应阵营
的原枪、正确 Combatant/GripMesh 引用、当前选中且已求值的后处理类及有效受保护
输入，再一次性调用现有装备与战斗启用接口。十秒游戏时间超时则关闭，不加
Python 行为或姿态循环；既有战斗、搜索、阵型预约服务不改。

五个正式 NPC 换成兼容的感知与 CombatV2 子类，保留标签、阵营、位置旋转缩放、
原人物网格/动作和现有枪 Actor；仅重接被替换角色的枪引用。玩家、两个选中握枪
策略、城市、导航保留。确保各一个阵型协调器和默认关闭的友伤策略。盟军跟随/
重组，德军初始守卫并使用既有有界搜索；不自动增加巡逻路线或任务目标。
