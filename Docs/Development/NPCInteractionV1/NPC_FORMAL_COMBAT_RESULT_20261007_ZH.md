## 本地变化

新增五个 FormalCombatV1 包，继承已测 CombatV2 控制器、行为树和兼容感知 NPC。
原生启动服务等正确枪引用、已求值且受保护输入有效的选中后处理就绪，再只调用
一次现有装备与战斗接口。十秒游戏时间超时则关闭。AI 决策与姿态都是原生，
已保存地图不依赖 Python 配置或驱动 NPC。

五个 NPC 保留原阵营、角色、变换、源网格/动作、100 血量、2 发已装弹/16 发
备用和原盟军挂枪 Actor。德军枪仍由已选中原生策略生成。地图中各一个阵型
协调器、全局友伤策略，友伤默认关闭。盟军跟随/重组并战斗，德军初始守卫并
使用有界搜索。不包含新增巡逻路线、目标或难度调整。
