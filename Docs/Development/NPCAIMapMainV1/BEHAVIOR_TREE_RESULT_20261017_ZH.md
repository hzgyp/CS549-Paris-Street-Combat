# 地图拖动与实际行为树已接入平台

2026年10月17日。资产管理平台原生 `/npc-simulation` 已支持鼠标左键按住地图背景拖动：长按240毫秒进入平移，快速拖动超过5像素也会平移。短按街道保留移动／摆放，拖动角色保留摆位。取消、丢失捕获、页面隐藏及切换回合／回访会清理手势。运行和回访时都可拖图，不会下达玩家指令。地图上有直接跳到行为树的按钮。

行为树已经参与实际执行：服务器共享节点定义驱动有界选择器、序列、条件、动作和保留意图修饰器，前端按同一定义画连接图。盟军按预算等待、共同分工支援／掩护、带敌情归队、独立队形跟随的优先级执行。德军按听觉警戒、真实视觉警戒／交战、丢失视线宽限、固定个人记忆的调查／有限搜索、返回／守卫选择意图，再执行对应真实导航。保留原先德军策略和盟军评分／分工算法。本轮为本地二维模拟树，未制作UE行为树资产。

可切换成员、展开完整树、定位执行节点、点击查看条件和动作结果。成功／失败／运行中／未执行分别着色；黑板显示观察、固定搜索原点／期限、路径结果、位置占用和有限请求次数。回访使用当时记录的树与黑板，并区分决策时刻和画面时刻。移动节点必须实际到达本次目标才成功；“保留意图”不表示到达，也不会隐藏子节点的路径失败。德军黑板没有隐藏玩家坐标。

验证通过：57项后端、6项客户端动画、TypeScript及网页构建；与保留旧引擎的六个完整120秒回合比较1,452帧，除新增树记录外原有结果一致。保留另一个已完成会话增加的全屏／适应窗口／缩放／拖动／收起详情，重新验证当前组合版本的20项原平台流程／81帧、23项树与拖动／52帧、8项播放控制。组合版本单独测量157次实际绘制、148次移动绘制，间隔中位数17.7毫秒、95分位18.1毫秒；156个连续姿态／1,866项净空和相邻线段检查通过，无浏览器未捕获错误。另有3项已完成窗口展示检查。这是本机有限场景证据，不代表所有机器或真实三维地图验收。
