# NPC 页面连续显示修复

10月17日，已安装到资产平台 `/npc-simulation`。原来每0.5秒收到模拟结果才重画一次；现在服务端额外提供每0.1秒实际移动的姿态，浏览器按显示帧连续绘制相邻片段，不预测位置、不跨过路径转角。模拟感知、决策、碰撞和有限搜索规则保持原样。暂停、摆位、回访、重置、切换页面会取消动画；后台页面暂停，120秒结束时显示最后一段后停止。

本机独立无头Edge浏览器、1480×1100窗口测量：2.6秒内167次绘制、164次位置变化，绘制间隔中位数16.7毫秒、95分位16.9毫秒，绘制耗时95分位0.4毫秒；原长路径基线中位数509.7毫秒。这是本机有限场景实测，不保证所有设备的帧率。

47项后端、6项播放轨迹、20项平台功能和8项新增控制检查通过；包括跟随、支援、搜索、拖选、暂停、单步、4倍速、回访、重置、回合结束及资产库。连续绘制的166组姿态、1986项位置／相邻线段碰撞检查通过。当前数据库、Catalog、JSON索引及访问凭证与安装前一致，没有刷新资产索引。原始测绘、算法、失败和证据保留，没有UE／游戏构建、外部发布或课程上传。详细数值、证据和回滚见[英文结果](SMOOTH_DISPLAY_RESULT_20261017.md)。人工交互设计与未来UE验收仍单独进行。
