## 目标与分工

用户建议用 GPT6.1 + Aholo + Blender 尝试机械类游戏资产。本试验暂以此前缺口清单中的 Kar98k 为外观候选；不是历史装备/部队型号正式批准。目标首先是德军NPC世界枪模，不把它扩大为完整第一人称套件。最终历史型号、日期/部队与可用性另验。

- AI负责参考梳理、命名部件、生成描述、检查与有限适配脚本。
- Aholo只尝试外形/PBR基础模型，不假设它会自动生成正确分件、活动轴、游戏动画或UE原生包。官方支持图片/文字转模型、GLB/PBR交付；“生产可用”宣传不替代本项目验收。[官方介绍](https://github.com/manycore-research/Aholo-Lux3D)
- Blender负责可见结构修复、分件、轴心、材质、有限可视运动及导出验证。只做数字游戏外观，不制作真实制造级内部结构。
- 新德军枪不能补玩家M1换弹。换弹另做同角色/同M1/同镜头的D059 Aim对照；本实施稿不授权角色/手指/镜头改造或正式换弹替换。

## 执行顺序与早期验收

1. 选定同一型号的可靠侧面、另一侧、俯视/三季度及局部参考；实际打开查看，记录角度、关系、来源/使用权限与不确定处。生成图不是历史参考。已检查巴黎博物馆同一把1943年馆藏的四张CC0原图：双侧、机匣顶面、底面局部；缺整枪三季度参考，后续用互补渲染检查深度。替换背带、缺准星罩/清洁杆是馆藏状态，不自动批准为标准德军装备。
2. 只读核对API余额、赠送来源/有效期、任务报价。本次实时API余额260，与300赠送减两次20的账目相符；网页300不作为可花额度。余额接口未暴露赠送有效期，不编造日期。本轮仅免费赠送额度，不充值/订阅。运行时为Blender5.2.2 LTS。
3. 本次保守自动提交上限20赠送积分、最多一次基础生成；费用须同时低于有效赠送余额和本地上限。未知提交结果保留预算占用，不自动重试；报价超过上限、来源/余额无法确认时不提交。分割/关节等额外收费功能关闭，不能用一次基础生成授权推断允许追加。
4. 原始输出只读保存并立即做低成本多视角检查。早期可证伪点：双侧和顶视轮廓可辨认、枪托/机匣/枪管关系连续，枪栓/拉柄不融合到不可分辨。长细结构、镂空护圈、准星细节有错误即明确记录。
5. 基础形态通过后，限定Blender分件/几何修复两轮。每轮重跑脚本并看双侧、俯视、三季度、枪栓局部；不得用材质遮丑。可视枪栓仅检查数字模型转动/平移中的分离、轴心和相交，不宣称真实内部机械准确。
6. 材质/UV/法线检查，导出GLB，在干净Blender进程重新导入，核对尺寸、部件名、轴心/层级、贴图、自相交和三角数。UE新鲜导入/运行适配属于后续单独工作包；本轮不打开正式UE工程。
