# 资产平台网络监听实施 — 2026-10-11

用户要求监听0.0.0.0以共享内部平台。已读项目交接、失败索引与既有Host/Origin/CSRF/会话检查；原流程即使改socket绑定也会拒绝局域网Host，且无凭证无法建立会话。因此一并调整监听、允许访问地址、同源校验和共享链接。

本机配置使用0.0.0.0:8766，启动器按该配置复用服务。允许实际本机IPv4地址及本机名称访问，Origin必须与请求地址相同；保留会话凭证、CSRF、CSP和文件边界。生成私有共享链接文件供用户发给授权成员，不把凭证写到日志或公共文档。

早期验收：局域网地址能够取得页面，带凭证登录后读取资产、3D和刷新接口；无凭证、未知Host、跨源、缺失CSRF仍拒绝。停止条件：需要用任意Host/Origin放行或关闭会话检查才能共享。Windows防火墙仅配置8766/TCP、本地子网、Private/Domain及实际Python程序，若需系统管理员权限则由Windows确认，不关闭整体防火墙。第二台机器/公网路由不由本机连通检查冒称通过。
