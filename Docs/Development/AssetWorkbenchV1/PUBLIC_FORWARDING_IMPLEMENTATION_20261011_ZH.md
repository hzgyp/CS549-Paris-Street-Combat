# 资产平台端口转发实施 — 2026-10-11

用户已配置路由器端口转发，要求组员通过公网访问。已读HANDOFF、Failures/README、NETWORK_SHARING实施/结果和既有网络认证测试。失败索引没有本平台的公网专属案例；当前代码检查直接确认两处阻挡：允许Host仅含本机接口地址，防火墙仅允许LocalSubnet。已有局域网检查不代表公网可达。

增加私有配置external_url，明确登记公网HTTP地址及外部端口；外部端口可以与本机8766不同。严格验证地址，不允许任意Host或跨源请求，保留访问凭证、CSRF及文件读取边界。共享模式启动时生成独立私有public-share-link.txt，重启后重生成，凭证不进入日志、Git或公开文档。公网IP改变后更新配置并重启。

路由器转发目标为本机IPv4及TCP8766。Windows规则仍限定当前Python程序、该端口及Private/Domain网络；公网转发使用RemoteAddress Any，由Windows管理员确认实际应用。原有LocalSubnet默认保留，脚本不关闭整体防火墙。

早期验收：测试公网Host及不同外部端口的登录/读取，未知Host、错误端口、跨源和缺失CSRF均拒绝；本机与局域网仍可用。停止条件：需要通配Host、关闭认证、扩大其他端口或停止无关服务。实际外部端口等待用户确认；仅在确认后配置并生成公网链接。路由器回环测试不等于另一网络验收，未观察到外部成功时明确保留该限制。
