# 3D 与动画预览实施 — 2026-10-11

范围：本机资产平台。优先当前人物、第一人称、步枪、动作库及候选地雷。保留原件、原生游戏资产、骨架、权重和已认可指姿；只生成私有浏览器预览副本，不发布。

采用 blender-character-workflow 的只读导出与变形验证步骤。已读 MI030（Blender/GLB 与 UE 表现分开验收）、MI033（等待真实截图完成）以及已有 FBX 修复/动画导出代码。本次改变展示层与明确登记的 GLB 服务，不改变游戏模型或重开人物制作。

控件：拖拽旋转、滚轮缩放、平移、复位、线框；动作选择、播放/暂停、时间轴和速度。中英文同步。标注模型/动画来源、版本、是否包含游戏整合覆盖；不把源动作当作最终游戏姿态。没有动画的模型不显示虚构动作。

格式与预算：自包含 glTF 2.0 GLB，内嵌贴图/缓冲，单项上限 128 MiB，按需加载，离页释放 GPU 对象。不提供任意磁盘路径或外部 URI 读取。GLB 来源与内容哈希登记，校验头部/资源范围/内嵌依赖后响应。

早期门槛：先载入确定的步枪和地雷 GLB，再检查已有角色/动作导出的骨架、权重、材质、动作范围及变形。角色导出若发生轴/尺度/变形错误，停止该版本，保留原件并定位转换原因，不通过摆动整个模型冒充骨骼动画。固定骨架不兼容的动作不得静默套用。

验收：实际 WebGL 画面、旋转缩放、暂停/寻帧/速度、离页与重载、版本及动画缺失状态；后端拒绝未登记/越界/外部依赖/哈希变化的模型。对导出副本做 fresh import 和多帧变形检查，报告浏览器通过范围，不声称新 UE 验收。
