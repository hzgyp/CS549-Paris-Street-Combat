# 资产索引自动同步实施 — 2026-10-11

目标：平台“刷新索引”同时更新SQLite快照、结构化资产索引及Markdown完整目录，新增或修改登记后无需另跑命令。沿用统一资产ID与来源，不扫描所有原件。

已读资产索引、HANDOFF、MI035与既有刷新/取消/哈希错误测试。MI035说明身份与结果必须区分；此次只在两类索引完成同步后报告成功。历史证据缺失继续显示未评估，不阻止正常元数据刷新或伪装为通过。

将独立脚本改为可复用的生成/发布模块，在原Importer成功收集和验证来源后准备资料索引；输出使用临时文件及替换，数据库发布失败或取消时恢复原资料索引。同步前核对来源指纹，拒绝刷新中发生的源变动；同一根目录通过锁串行发布。任务返回同步范围，界面中英提示与规则/交接说明同步更新。

早期验收：隔离测试工程新增/重命名资产后，经真实刷新接口两份资料索引与数据库同时更新。再验证目录写失败、数据库提交失败、取消、来源漂移和旧证据缺失。停止条件：任一输出发布失败或来源身份变化；保留旧快照与旧资料索引，页面报告失败，禁止仅因数据库更新就声称全部同步。
