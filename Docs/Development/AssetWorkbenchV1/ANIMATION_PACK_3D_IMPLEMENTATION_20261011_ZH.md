# 动画包3D预览实施 — 2026-10-11

目标：125个动画包可以检索和选择包内实际AnimSequence，在现有WebGL查看器中播放、暂停、拖动时间、改变速度、旋转、缩放和复位。原始包、游戏模型、骨架、动作及用户UE会话不改写。预览是中性材质的浏览器副本。

已读MI030、MI033，以及本平台封面替换结果：原生成功导出不能替代视觉检查；异步加载必须完成后再取图；分离网格与动作的简单绑定造成过偏差。因此沿用UE联合导出网格与动作，Blender直接转换为独立GLB，不做骨骼重定向。Movement缺失预览人偶的既有依赖需继续显式标注。

先使用125包已经验证的默认动作创建可直接打开的GLB；通过原生AssetRegistry枚举各包实际AnimSequence，排除Blueprint/Montage/BlendSpace等非独立动作，但保留成员库存。动作按需在独立私有工程转换、缓存；界面显示准备、成功或具体失败状态，不将未转换项宣称已经播放验证。任务串行，输入只来自登记清单，不接受客户端文件路径或命令。

早期验收：一个真实包的默认动作GLB在浏览器正常变形；另选一个未缓存动作，经真实UE导出、Blender转换后正常播放；快速切换不会显示上一动作。通过后展开125包默认动作与全量动作目录。GLB限制沿用128MiB、自包含资源与哈希校验；源文件校验失败、找不到匹配网格/骨架、导出崩溃或输出无动作均停止该项并保留日志，不替换为别包动作。首次准备可能需要启动本机UE辅助进程，不能伪装为即时完成。

验证包括默认动作覆盖、原始动作身份、模型加载/切换竞态、搜索、播放暂停/时间轴/速度、旋转缩放、中英界面、未授权请求、路径和哈希拒绝、任务并发限制及原有3D回归。最终浏览器检查只覆盖实际运行样本，不能声称每个动作均已完整播放或达到游戏质量。
