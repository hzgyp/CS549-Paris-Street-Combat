# 3D 与动画预览结果 — 2026-10-11

本机已实现。229条库存保持；6个资产条目接入3D：德军人物、盟军人物、第一人称手臂、德军步枪、步枪动作库、候选压力地雷。盟军/第一人称页面另可选择 M1 来源模型。共登记6个GLB文件，模型与资产为多对多关联。

## 使用

详情默认进入“3D 与动画”；左键旋转、滚轮缩放、右键平移、复位和线框。复位适配当前姿态，死亡动作也可重新取景。人物/手臂含7段已有骨骼动作：待机、走、跑、单发、换弹、受击、死亡。支持播放/暂停、时间轴、0.25–2倍速。步枪和地雷明确显示无内嵌动画。中文/English切换保留当前预览；图片/音频页继续可用。

## 保留的问题与修正

实施前已读MI030、MI033及既有角色导出流程。export-v1在更新依赖图前读取对象矩阵，参考骨位置异常，停止采用；export-v2固定矩阵更新后德军正确，但1 cm兼容门槛拒绝既有盟军约23 mm体型差异。export-v3使用显式父子绑定矩阵及5 cm有界体型差检查，并通过重新导入的独立位置验证。v1/v2报告与生成件保留在私有目录，未登记到最终预览。

fresh-import检查第一轮误用Blender默认24 FPS导入、再以30 FPS寻帧，产生约0.1 m采样差；改为导入前设定30 FPS后上述误差降至约0.0000101 m。这是验证时基错误，不是放宽变形阈值。浏览器测试修正了复位残留阻尼，以及第一人称默认误选M1静态模型。时间轴测试改用真实鼠标/键盘操作，替代不支持的range填值。

当前保留两项构建环境提示：Three.js懒加载块约616 kB，超过Vite默认500 kB提示；Starlette测试客户端的httpx接口弃用提示。均未隐藏，不影响已执行检查。人物原生材质/握姿整合仍属于后续精确预览工作，本次没有假装完成。

## 存储与接口

`private-records/models.json`登记路径、SHA-256、版本、来源、动作和本机受众；API只返回显示元数据，下载由认证专用接口按不可变快照解析登记ID。读取时核对Windows安全路径、实际哈希、GLB头部/缓冲范围、自包含依赖和128 MiB上限。禁止任意路径与外部URI；不改动普通媒体接口的格式范围。前端按需加载Three.js，页面离开释放纹理、网格、动画和WebGL上下文；不可见页停止绘制/动作推进。
