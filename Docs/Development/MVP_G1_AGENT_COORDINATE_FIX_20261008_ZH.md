# G1代理坐标与桥头到达修正

2026年10月8日。[英文原稿](MVP_G1_AGENT_COORDINATE_FIX_20261008.md)。已读Failures/README、
MI001、ML010、MI004／MI005／MI006及原生路线／渲染计划。本次是停止光追试验后的
不同、有实测依据的修正，不重开任意多边形／偏移／AI参数尝试。正式758／359／703、
资产／模型／手指／动作／枪／Catalog保护，只写新私有G1包装。

queries_v1／instrument_v11完成12个固定只读查询，退出0，实际默认范围(100,100,120)cm。
六个中心起点均无法投影／寻路，六个脚底起点均完整通过，且保持原身体目标也通过。
因此这次见证只需改预检起点坐标。UE Character::GetNavAgentLocation返回脚底，
同步查询不替换传入起点，原生MoveTo本来就使用脚底。

运行时复制G1原行为树，只替换一处选中BTT_PC_NPCPlanV3为原生等价任务，保持原
生命／启用／耗尽准入，HomePoint／HomeCaptured／PatrolLeg，全路径要求、任务／请求
ID、代次、DesiredPosition／HasMoveGoal／WaitingReason及成功失败语义，仅预检起点改
GetNavAgentLocation，目标／黑板仍为原身体坐标。其他任务／服务／装饰器、阵营感知
战斗动作、最多2重试、预约／RVO／MoveTo均原逻辑，不存源BP／行为树。每世界Ready前
复制一次，控制器各自黑板；必须恰好替换一个，原BB及其他节点类／服务拓扑一致。

独立到达契约缺陷：盟军2距有效目标32.782cm，但目标X5609.018使身体停在X5576.600，
没过原X5600；原700cm尾随及缓存目标可能让停在T1的玩家无法带后员完全过桥。修正
实际汇合阶段，不改门槛：行进仍450／700cm；玩家自然停在T1的55cm内后锁定桥头汇合，
沿原最后一段，用原间距700-450=250cm，距同一终点250／500cm两个目标。实测末段625cm、
起始X5833，必须长>=500+55且两端X>=5600+55，否则停。两目标在已有桥头道路、间隔250cm，
与玩家保持距离。这是依据实测几何的阶段转换，不扫描偏移；锁定至原过桥完成，玩家
继续走时不能再把后员派回桥上。原预约投影／RVO、实际55cm／25秒／身体X5600不变。

候选指纹后缀改BridgeConstraintV2FeetPlan、默认ParisG1V4，旧档保留、原校验不变，
原生城市仍只排除已见证一块。不增加禁行／胶囊速度／伤害弹药／枪／模型姿态或改写
广泛阵营AI。包装内计划任务确实是导航实现变化，不能声称全部AI字节不变，也不能拿
旧原树测试替代新版证据。
