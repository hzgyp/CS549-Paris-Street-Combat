# V14 — 深色涂饰木材，有界实施

2026-10-04。用户明确纠正：V13问题主要是木色和涂饰感，并不是划痕数量。
本工作包仅为木材底色/表面响应重新开放迭代，不继续V13做旧细节。
只做私有候选；不改UE/游戏/SFTP/Catalog，不用云端、不消费、不提交推送。

## 目标及失败复盘

已读Failures/README、GP004（错误材质归属）、GP009（导出漏倒角）、V12
过亮光泽预览、V13弱提升及遮罩重载诊断。此次改的是完整木材的颜色/涂饰
响应，而非增加磨损数量。使用已有三个木材材质，侧面及端面一起处理，不做
坐标分类。保护24部件/24,466三角/1.1073米枪形、UV、几何法线、变换、
全部金属材质及所有纹理法线。沿用已有木纹和磨损位置。

采用Blender建模skill的5–7阶段；1–4阶段复用已认可枪形。普通游戏道具精度，
不重建形体。目标为温暖深棕胡桃木、可辨木纹和克制的半哑光涂饰；已有露木
磨损与完整涂层形成对比。盟军M1仅作本机外观参考，不认定历史漆法或UE等效。

## 执行及早期验收

1. 只读诊断V13节点/像素，明确颜色空间，再记录底色、粗糙度、反光和法线输入。
2. 独立GermanRifleWoodFinish_v14源码、LocalWorking私有输出，从V13 finish_v2
   打开，仅改木材D/ORM及适度反光响应。不加划痕/clearcoat扩展，不动法线和金属。
3. 固定相机、灯光、曝光，检查整枪/枪托/机匣/护木及无光照底色。应变深暖棕，
   木纹仍在，端面不发白，无塑料般大块白反光或死黑。最多一次有原因的修正，
   使用新目录，不扫参数。
4. 六视图及木材近景；应用修改器导出GLB，重新导入比较几何、材质绑定和图片；
   所有非木材及法线PNG载荷不变。干净重跑检查属性/图片，不假定GLB全文件相等。
   生成相同条件的M1/V13/V14对比图。
5. 写实际结果、限制、诊断哈希，交用户看效果。

## 停止和回退

早期证据补记：preview_v1五张实图已检查，无光照木色正确，但机匣/护木PBR
白反光过大，未通过早期外观条件。唯一因果修正：反光系数.5→.18，粗糙度
均值约.43→.52；底色、遮罩、灯光不变。须核对KHR_materials_specular在GLB
及新导入里保留，不加clearcoat。保留初稿和冻结源码，不再进行第三次修正。

几何/非木材/法线/输入哈希变动或颜色处理不能证明即停。唯一修正仍不合格，
保留证据说明，不加细节或改灯光掩盖。绝不覆盖V13；回退只是V14不选入生产，
不是恢复游戏。完成本轮即交外观评价。授权、历史、机构、骨骼动作、接触、
UE/贴图mip/性能及生产选择仍独立待验收。
