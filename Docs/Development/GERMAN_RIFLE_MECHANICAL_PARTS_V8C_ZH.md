# Kar98k V8C：独立机械部件灰模

2026-10-03。在用户批准的机匣/照门/枪口重建范围内，已阅读 GP001–007 和 V8/V8B。两条依赖原曲面自动补面的路线已停止；原枪、木托、背带、球头和游戏均不改。本步只做独立的机械部件，**不叠在旧网格上掩盖问题，不切掉旧枪冒充整合成功**。

制作独立命名的机匣前后环、开口下托、枪栓圆柱/后盖/保险/抽壳条，照门底座/倾斜表尺/滑块/缺口/销轴，以及中空枪口、准星座/刀片和前箍。暂不替换拉机柄/球头、木托、背带。使用原枪 1.105m 临时尺度/轴向趋势和博物馆照片作粗略参考，不宣称尺寸/型号史实精确或已配合木托。

先灰模，检查双侧/顶底/斜视和部件近景：曲面规整、抛壳开口/枪口孔/照门缺口可见，没有乱薄片或遮盖板；每个实体边两面、正体积、UV 和有限尺寸明确。通过后添加自己常量式 glTF 钢材，打包 blend/GLB、重新导入、多角度、干净复现和旧文件哈希保护。脚本在 `Tools/AssetCreation/GermanRifleTopologyV8/`，私有产物使用独立 `parts_*_v1` 身份，不覆盖任何旧轮次。

最多一次有明确证据的结构纠正，失败就停止。成功也仅交付未选中的独立部件，不是可用整枪、完整可动枪栓、换弹/史实/游戏验收。装回原木托仍需独立接口验证或人工美术整合；不重启已失败的盒切/凸包/描面。无云端、收费、UE、SFTP/Catalog、提交推送或其他功能开发。

首次灰模发现照门楔块侧面角点顺序交叉，出现黑色底面/锯齿；单看边两面和正体积漏掉此错误。保留首次灰模与源快照。唯一一次结构纠正：修正六个面的顶点环顺序，增加凸面各角点方向检查，先输出 `parts_clay_v2` 重查，不调整尺寸扫参数、不改原枪；仍失败则停止。
