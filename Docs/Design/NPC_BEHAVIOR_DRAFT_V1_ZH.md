## 动作叶子与当前能力

树中的A编号是设计动作标签，不是现有UE函数名。组合叶子按箭头顺序执行，执行前检查角色、骨架、武器、姿态、碰撞和生命周期；拒绝后走明确的待机/等待分支，不能只改Blackboard就声称人物做了动作。

| 标签 | 实际人物动作 | 可用程度及映射 |
| --- | --- | --- |
| A00 | 停下并待机；有合法武器时普通持枪 | 沿用现有待机/持枪；没有武器不生成隐藏枪或伤害 |
| A01 | 步行到指定位置，抵达后A00 | 原Stride及MoveTo基础已测；共享NPC步速/动作请求适配待接 |
| A02 | 跑到指定位置，抵达后A00 | 玩家V6跑步功能已测；NPC按队伍适配待接；跑动不射击/换弹 |
| A03 | 低速走到检查点，抵达后A00 | 玩家V6低速移动已测；不是已实现潜行/听觉 |
| A04 | 停下 → 站姿 → 转向目标 → 普通持枪 → 射击事务 | 玩家射击/挡枪/扣弹已测；NPC接入、已有Rifle_ShootOnce候选的适配及后坐/枪口效果未验收；不是ADS |
| A05 | 停下 → 站姿 → 持枪 → 简化换弹，完成后A00 | 原守恒/中断事务已测，泛用动作不是M1专用换弹；NPC接入待做 |
| A06 | 跳跃，随后落地回合法待机/移动 | 玩家V6起跳/空中/落地已测；NPC缺NavLink/落点验收，首版树禁用 |
| A07 | 死亡动作一次，之后保持Dead | 原生命状态/死亡/复位已测；不能每次树更新都重播死亡 |
| A08 | 停止移动/攻击，待机并有限等待 | 已有停止能力；NPC等待原因、期限及恢复分支待接，不是新的等待动画 |
| A09 | 任务层授权的复位/快照恢复 | 单位复位接口已测，任务检查点还原未实现；NPC树不自动调用复活/补弹 |
| A10 | 待机中转向或移动中朝向调整 | 提议通过UE角色/控制器朝向实现，NPC接入与脚底滑动需验；专用原地转身/头眼观察动画未验收 |
| A11 | 蹲下/蹲走，空间允许时站起 | 玩家V6四方向蹲走功能已测，视觉及盟德NPC适配未过；首版NPC策略禁用，不能蹲射/蹲姿换弹 |
| A12 | 趴下/前后爬行，空间允许时站起 | 玩家V6局部碰撞功能已测，视觉及NPC适配未过；首版禁用，不匍匐射击/侧移/转向 |

“停止”“观察”“瞄向目标”是角色动作组合或朝向控制，不等于已有独立动画文件。射击的逻辑事务与身体开火动画、枪口闪光、命中反馈分别验收，不能用前者替代后者。受击、转身或胜利等专用动作未验证时明确留缺口，不自行造详细人物或假装动画齐全。状态依据见 `Docs/Development/PLAYER_ACTIONS_RESULT_20261003_ZH.md` 与 `WEAPON_PRESENTATION_AND_PLAYER_ACTIONS_V1.md`。

## 总体结构

五个NPC共用一份AIController和Behavior Tree定义，但每个NPC拥有独立控制器、Blackboard、目标记忆和动作状态。Team、Role、EncounterGroup、PatrolRoute、SearchZone由实例配置。初始为两名盟军队友、三名德军，不做无限刷兵；具体路线和后续有限增援组仍由城市勘察、节奏及性能测试决定。

行为树决定“想做什么”；人物动作层决定“现在能不能做”，导航层决定“能不能到那里”。开火、伤害、换弹提交、死亡与复位仍使用已验证接口。AI不能直接改弹药、跳过障碍或把动画播放完当作射击命中。

## 决策优先级

从上到下选择第一个满足条件的分支。高优先级打断低优先级；取消必须释放当前移动请求及目标预约，并用生命周期代次拒绝旧回调。

```text
每个NPC的优先选择器（从上到下，第一条适用分支优先）
├─ 1 本人死亡？
│  └─ 取消移动/换弹与预约 → A07死亡一次 → 保持Dead
├─ 2 任务冻结或任务失败？
│  └─ 取消当前任务 → A08停止/待机；等待任务层授权A09
├─ 3 当前有不可直接抢占的动作？
│  ├─ 合法换弹进行中 → A05继续；暂不射击
│  └─ 必须取消/姿态过渡中 → 用原事务安全取消/完成 → A08 → 重新判断
├─ 4 有实际可见、仍存活的敌人？
│  └─ 接敌子树（最终落到A00/A01/A02/A04/A05/A08/A10）
├─ 5 有未过期的最后目击记录？
│  ├─ 盟军 → A00+A10短时警戒 → 盟军职责子树，不无限追敌
│  └─ 德军 → A01/A03走到有限可达检查点 → A00+A10检查
│            搜索超时/检查点用完 → 德军职责子树
└─ 6 没有接敌/搜索任务
   ├─ 盟军 → 盟军职责子树
   └─ 德军 → 德军职责子树
```

首版NPC不请求A06/A11/A12。若异常残留低姿态，动作层先等待合法恢复；顶板挡住起身时保留当前姿态并A08，绝不强行站起或开火。高优先级死亡/冻结仍能安全中断动作门。

移动失败恢复是各个MoveTo任务的局部处理，不是压过接敌的永久全局分支：有限等待、最多两次重规划，仍失败进入Waiting并报告原因。不瞬移、不无限重试；等待期间仍更新真实感知，出现可见敌人可中止旧移动，进入合法战斗分支。这样不会出现“路被堵了就连眼前敌人也不处理”。

普通持枪与瞄准是不同显示状态。本轮不增加ADS。NPC初版作战采用已验证的站姿动作；蹲姿、匍匐只有在本轮人物运行与枪手接触验收通过后才能纳入策略，不把玩家有按钮等同于双方AI动作已验证。

## 接敌子树

```text
可见敌人（每次射击前重新检查，不能依赖过期可见状态）
├─ 盟军没有有效活玩家，或短追距离边界已超限？
│  └─ 取消追敌移动 → 盟军职责子树归队/等待；不得因敌人仍可见就继续追
├─ 当前没有合法武器？ → A00+A10警戒，不扣弹/不造伤害
├─ 有武器但装填弹数为0？
│  ├─ 有储备弹药且动作门允许 → A05站姿换弹 → 重新判断
│  └─ 无储备/不能换弹 → A08等待并记录原因；不自动补弹
└─ 有可用弹药
   ├─ 距离/职责范围不允许射击？
   │  ├─ 盟军有获准可达点且短追预算允许 → 短距离追敌子树
   │  ├─ 德军职责范围内有获准可达点 → A01/A02移动 → A00
   │  ├─ 自身已经离开获准职责范围 → 对应职责子树返回，不继续追敌
   │  └─ 范围内没有合法点 → A00+A10警戒
   └─ 距离与职责允许
      ├─ 视线或枪管/枪口被世界或友军挡住？
      │  ├─ 另一个已预约支援点可达 → A01移动 → A00 → 重新判断
      │  └─ 没有合法点 → A08等待；持续感知，不穿墙/穿友军射击
      └─ 射击通路合法
         ├─ 仍在跑动/低姿态/换弹/冷却？ → 安全停止/恢复 → A00或继续A05
         ├─ 朝向尚未合适？ → A00+A10转向，仍不射击
         └─ Ready站姿且朝向合适 → A04射击 → 等冷却时A00 → 重新判断
```

“找点”“预约”“检查视线”是准备条件，不是人物动作叶子。每个找点结果必须变成移动、抵达待机或拒绝后的等待。朝向通过A10协调；完整ADS、靠墙探身、掩体贴靠及开镜动作都不是当前树的隐含能力。

射击后的双方交互也必须落实到角色结果：

```text
A04请求射击，由原事务判定拒绝或发射
├─ 武器近墙/近友军检查拒绝开火 → 不产生射击/伤害，沿用原拒绝扣弹规则
├─ 已发射且先命中世界 → 无人物伤害 → 射手A00/改位置；命中效果待接
├─ 已发射且先命中友军 → 检查统一FriendlyFireEnabled
│  ├─ 关闭 → 友军不扣血，子弹不穿透至后方敌人
│  └─ 开启 → 对该友军执行一次正常伤害 → 下方存活/死亡结果
└─ 先命中敌军，或友伤开启后命中友军 → 正常伤害结果
   ├─ 目标仍存活 → 更新真实生命值 → 继续合法动作
   │              独立受击反应动画未验收，不伪造倒地/硬直
   └─ 目标死亡 → 目标A07 → 取消其移动/换弹/预约
                  其他NPC清除死亡目标；有限组死亡记录更新，无替补刷新
```

## 两方如何互动

| 情况 | 盟军 | 德军 |
| --- | --- | --- |
| 尚未接敌 | 跟随玩家，保持各自位置，落后时归队 | 守卫配置区域或徒步巡逻 |
| 接敌且有射击通路 | 允许短距离追敌；到不同支援位置停下，攻击实际可见敌人 | 停止巡逻，攻击实际可见盟军 |
| 被掩体阻挡 | 等待或改到可达支援点，不穿墙开火 | 保持警戒或换可达射击位置 |
| 目标消失 | 短时警戒，然后归队，不无限脱离玩家 | 检查最后目击区域，搜索超时后返回职责 |
| 路口被友军堵住 | 后到者等待，重新预约另一个点 | 同样等待与有限重规划 |
| 队友或敌人死亡 | 更新真实死亡记录，不补出替代士兵 | 相同原则，保留已发生的伤亡 |

已确认统一的FriendlyFireEnabled配置覆盖玩家、盟军NPC和德军NPC：开启时对实际命中的友军计算正常伤害，关闭时不计算友伤。两种模式下友军身体都挡弹，不穿透后面的敌人。初始值沿用当前已测的关闭模式；配置切换与开启模式尚未实现/验证，不能把旧关闭模式回归当成新功能通过。AI两种模式都尽量避免向友军挡住的枪线开火；合法发射后友军走入弹道等命中由统一伤害入口处理，AI避让不等于全局免友伤。误伤不改变Team，不自动开启报复或叛变。感知按敌我过滤；没有看到敌人时不能因玩家位置已知就获得敌人的隐藏位置。首次版本不做声音传播、压制、投掷、车辆、无限搜敌或复杂战术。

## 盟军职责子树

```text
没有更高优先级任务的盟军
├─ 没有有效活玩家？ → A08停止待机，等待任务层处理
├─ 与玩家距离超过归队阈值？
│  ├─ 独立归队点完整路径可达 → A02跑到归队点 → A00
│  └─ 不可达/瓶颈被占 → 有限恢复子树
├─ 不在跟随距离带，或玩家移动使跟随点失效？
│  ├─ 自己预约的跟随点可达 → A01步行（需要追赶且获准时A02）→ A00
│  └─ 不可达/瓶颈被占 → 有限恢复子树
└─ 已在合适跟随/支援位置
   ├─ 需换到不同、且不挡玩家枪线的点 → A01移动 → A00
   └─ 无需移动 → A00普通持枪+A10朝向合法警戒方向
```

已确认盟军允许短距离追敌，同时保留支援玩家和归队边界。原地不乱走不等于AI失效：只要位置已合适，待机就是合法动作结果。

```text
盟军短距离追敌（来自接敌子树，只追实际可见敌人）
├─ 玩家死亡/无效、目标死亡/丢失视线、距离预算耗尽？
│  └─ 取消追敌移动/旧预约 → 盟军职责子树归队（A01/A02→A00），不可达走有限恢复
├─ 可达射击点同时在玩家支援范围和追敌距离预算内？
│  └─ A01步行或A02跑步到独立点 → A00停止 → A10转向 → 合法时A04射击
└─ 无合法点 → A00+A10警戒，不强行追；已偏离队伍则归队
```

初轮提议AllyChaseMaxDistance为10米，同时约束与当前玩家的距离以及本次追敌累计移动距离；跟随/归队仍采用下述调试阈值。每次更新移动目标前复核完整路径及剩余预算，执行中监控实际累计位移，不能一路更新目标绕过“短距离”。追敌起点/预算不因总树重评估或换目标清零；返回合法跟随带并结束追敌任务后才可开启下一次追敌。10米是调试初值，按街道测试调整，不是用户指定的最终数值。丢失视线就结束追敌，不加入盟军隐藏目标搜索。

## 德军职责子树

```text
没有更高优先级任务的德军
├─ 搜索刚结束且不在职责位置/路线？
│  ├─ 返回点可达 → A01步行返回 → A00
│  └─ 不可达 → 有限恢复子树
├─ Role为Guard？
│  ├─ 不在守卫点 → A01返回守卫点 → A00
│  └─ 在守卫点 → A00待机+A10有限朝向警戒
├─ Role为Patrol？
│  ├─ 有合法巡逻路线及下一点？
│  │  ├─ 路径可达 → A01走到下一点 → A00+A10短停检查 → 更新巡逻序号
│  │  └─ 不可达/被堵 → 有限恢复子树
│  └─ 路线为空/配置错误 → A08待机并记录原因，不随机瞬移
└─ Role无效 → A08待机并记录配置错误
```

已确认德军丢失视线后限时搜索。搜索子树只使用该NPC最后一次实际目击的位置/时间，选择有限可达检查点；到点动作是A01或可选A03，加A00/A10检查。SearchDuration调试初值提议15秒，超时或点用完就取消搜索移动、释放搜索预约并返回职责；再看见敌人才切回接敌。期限内没有任何可达点也结束搜索，返回职责或有限恢复，不永久堵在搜索分支。不会通过“搜索”标签获得隐藏目标的实时坐标。

## 导航失败如何落到动作

```text
当前移动失败/瓶颈被占
├─ 本人已死亡/冻结？ → 总树的A07/A08
├─ 可见敌人出现且允许接敌？ → 取消旧移动/预约 → 接敌子树
├─ 已用重规划次数少于2次且任务仍合法？
│  └─ A08短停等待 → 重新选获准可达点 → A01/A02/A03移动
└─ 超限/没有合法点 → A08等待并记录原因
                     感知或任务/路径条件改变后才重新评估，不每帧无限重试
```

同一时间每个NPC只拥有一个当前动作请求和一个有效移动请求；停下必须实际停止位移。参照匍匐失败案例，不能只看速度零或状态名，验收还要看连续位置和身体空间。

重试预算按行为任务编号累计，不能每次回到总树就清零。相同目标/相同拒绝原因持续存在时等待条件变化，不每帧重发失败请求。Running动作只观察完成反馈，不重新开始动画或重开换弹事务。

## 队友支援位置与导航

一个轻量小队协调器只管理目的地预约及瓶颈等待，不共享全知敌人记忆。它为两名队友选不同可达点，检查NavMesh完整路径、地面、身体空间及不挡玩家射线；到达后预约继续保留，直到换任务、失败、死亡或复位。

提议初值：普通跟随距离3至6米，超过10米进入归队；目的地至少间隔1.5米。只用于第一轮调试，必须按实际街道测量调整。瓶颈先到先走；后到者短暂停留，最多重新规划两次，仍失败就Waiting。不要同时堆叠两套互相冲突的避让系统。保留“独立目的地”对照模式，用相同起点、目标和NPC数比较碰撞、堵塞、到达时间与失败次数。

## 目标记忆与参数

每个NPC保存：Team、Role、Group、Home、PatrolIndex、TargetActor、LastSeenPosition、LastSeenTime、SearchDeadline、DesiredPosition、ReservationID、MoveRequestID、RetryCount、WaitingReason及RestoreGeneration。丢失视线立即停止更新LastSeenPosition；确认目标死亡后清除TargetActor及对应搜索记忆，不继续找已知死亡目标。视线重新获取才恢复跟踪。盟军短时警戒与德军搜索的期限从实际丢失目标时开始，回到总树不重置期限。Team/Role配置不合法时A08并报告原因，不默认成敌方或随机职责。

配置层保存统一FriendlyFireEnabled；NPC私有状态另含ChaseTaskID、ChaseOrigin和ChaseTravelDistance。德军SearchDuration暂用15秒、盟军AllyChaseMaxDistance暂用10米作提议调试初值；射程仍按武器及实际城市测试确定。所有阈值可配置，不在本稿中锁定整场任务时长或地图范围。

## 动作接口与实施顺序

建议新增共享动作适配层，但下面是契约设计，**不是已经存在的API**：行为任务提交动作标签、目的地/目标、请求编号和RestoreGeneration；动作层返回Started、Running、Completed、Rejected或Cancelled及原因。逻辑动作标签A编号、提议的请求编号与现有换弹ActionID必须分开，禁止覆盖原事务身份。

动作完成由实际到达/合法姿态/原动画阶段及事务结果判定，不用行为树计时器直接产生弹药或伤害。更换行为任务或目的地时取消旧MoveTo并释放旧位置；同一支援任务的“抵达→待机→射击/换弹”保留位置预约，不因动作切换就让另一个队友挤进来。换弹取消仍带原ExpectedActionID/Generation，提交前不转移弹药，提交后不退款，过期回调不能再提交。任务层的A09必须按选定快照恢复角色/NPC/目标状态，没有检查点才从头开始；现有单位复位测试不等于完整检查点已实现，也不能自动加血/补弹。

首轮需要站立待机、步行、跑步、普通持枪、开火事务、简化换弹、死亡及复位。玩家新增静步、跳跃、蹲下和匍匐分别验收；NPC跳跃需要额外NavLink和落点验证，暂不自动接入。没有独立潜行动作不阻碍低速移动，但低速不等于已有隐蔽系统。没有二战专用换弹或德军匹配步枪时，继续明确记录资产缺口，不用现代枪替代。

本轮新增动作接在独立玩家试验类上，不声称德军骨架已完成同样的蹲趴适配。低姿态暂禁止射击/换弹、匍匐暂只允许前后移动且只进入较平地面；第一人称跑跳维持已有普通持枪，尚无专用冲刺举枪/收枪动作。AI实施前须建立共享动作接口，并逐个验证盟德角色，不直接将玩家试验类批量替换NPC。

德军尚没有已接受的匹配步枪。射击分支必须检查合法WeaponAppearance及弹药接口；未装备时只允许感知、警戒和移动，不凭空造成伤害。可以先开发感知/职责，但双方完整战斗闭环要等德军武器完成兼容及历史复核；不自动拿盟军M1或现代枪替代。缺口见 `Docs/Development/ASSET_GAPS_20261003_ZH.md`。

这三项玩法已确认；下一次实施仍先另写AI实施文档，并完成相关基础动作人工复核，再按“单NPC感知与职责→两个队友目的地与预约/短追→三名德军搜索与射击→可配置友伤、六人互动和死亡复位→任务闭环”的顺序开发。规则确认不是本轮自动开始开发，也不是再做一轮外观精修。

验收必须实测：独立记忆、敌我过滤、遮挡停止射击、丢视线不作弊、搜索超时、不同支援点、预约释放、堵路有限恢复、死亡和旧回调拒绝，以及独立/协调目的地对照。真实城市、原生运行、日志及画面证据都要有。编译通过不算AI完成；NPC数量、帧率和整场任务仍单独验收。

每条叶子的验收还必须能追溯“判断条件 → 行为任务编号 → 请求的A动作 → 接受/拒绝原因 → 实际动作及结束结果”。步行/跑步看连续位移、步态与抵达；停止看位置稳定；转向看朝向与脚底接触；射击看持枪动作、合法枪线和一次扣弹/伤害；换弹看原阶段提交与中断守恒；死亡看只执行一次及取消旧任务。仅日志标签变了、Blackboard有值或计时器到点，都不能代替人物实际执行。未验收动作不得进入正式树，使用本稿明确的待机/等待降级分支。

## 已确认规则与新增验收

2026年10月3日Yupu确认：盟军允许短距离追敌；友伤开启就计算、关闭就不计算；德军丢失视线后限时搜索。无需再次请求这三项玩法选择。距离与时间用可调初值，实际数值仍需测试。
