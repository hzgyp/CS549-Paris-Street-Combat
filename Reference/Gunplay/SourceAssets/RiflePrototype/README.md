# Rifle silhouette study

Two centimeter-scale source meshes generated by `Development/Scripts/generate_rifle_blockout.py` and imported by `build_g1_weapon.py`:

- `SM_Rifle_WoodStudy`: stock and fore-end silhouette.
- `SM_Rifle_SteelStudy`: simplified barrel, receiver, sights and trigger guard.

Visual reference: the existing library's `HistoricalReference/images/weapons/us_garand_carbine.png`, with context and source limitations in `HistoricalReference/03_WEAPONS_AND_AMMUNITION.md` and the image catalog. The M1 remains a candidate, not an approved scenario-specific weapon. Geometry is an original coarse study, not a scan or dimensionally validated reconstruction; no archival image is embedded as a game texture.

The gameplay prototype uses eight rounds, semi-automatic requests, a 0.25 s cooldown and empty-only reload. A guarded timer commits ammo at 1.4 s and ends the action at 2.4 s. These are provisional gameplay timings. There are currently no hands, clip mesh, clip ejection or reload montage; lowering the gun is temporary visual feedback. Do not present this as completed historical weapon animation.
