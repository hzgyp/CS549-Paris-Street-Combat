# GP004 — 木托/金属的坐标标记不是实际表面分界

2026-10-03。本机 Blender V4，用户明确授权继续精修。先读 GP001/002/003，改用保留全部原面与 UV 的材质标记，避免盒裁/凸包损伤。实施及最终结果见 `Docs/Development/GERMAN_RIFLE_SURFACE_REFINEMENT_V4.md` / `GERMAN_RIFLE_SURFACE_RESULT_20261003.md`（中文结果 `_ZH.md`）。

## 实际失败与证据

- 原生成贴图木/金属的颜色与金属度重叠，不能充当自动语义标签。
- 矩形上部条带 `interface_v1b` 只涂到枪机上半段，造成金属/木色错误断层。材质改变不等于清晰分件。
- 在实施文档中先声明不同的逐段轮廓/接缝标记，唯一 `contour_v1` 扩大覆盖，却误涂相邻木托、漏涂枪柄与保险/照门。从实际侧面/顶部/斜侧图确认失败。
- 没有删除几何、裁切、封口、加盖板或改木托，但仍有明显视觉缺陷。没有执行几何精修，停止两种标记机制，没有第三轮坐标调参。
- 首次导出 API 参数失败以及首次独立复核的浮点计算路径失败原样保留。不得用 Blender exit0掩盖 traceback。正确导出与精确源保护只证明文件安全，不证明材质通过。

## 可保留的基础设施

全原面/UV保存、木托与接触顶点保护思路、打包材质、新鲜 GLB 导入、固定灰模/材质相机、独立源比较及旧清单 SHA 检查。不能复用错误坐标标签作为认可边界，不能运行其 `--geometry`。

## 下一次必须改变什么

使用实际网格表面明确选面/面环、经过核对的人工语义分件，或成熟兼容资产的有限适配。先验证一个真实接缝的侧/顶/反向近景，核对漏涂与误涂，再进行形状精修。原材质图中模糊的一体化区域不应靠更复杂坐标包络推断；禁止再扫阈值、覆盖失败接口或仅靠暗色材质遮盖软形体。若真实分界仍不能确认，停止而非扩大改动。
